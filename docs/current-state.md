## 当前正在解决的问题

> **真实的伴侣选择和共同生活，到底由哪些不同因素组成，它们之间怎样相互影响？**

目标不是马上得到一个游戏属性表。

而是先建立尽量完整的领域认识，再裁出简化游戏模型。

## 当前几个关键待验证假设

1. 人的优势通常会通过时间、精力、钱和注意力投入产生机会成本，但不能机械理解成“一个高，另一个必然低”。
2. “能否接受缺点”需要进一步拆成频率、强度、情境、持续时间和双方修复能力。
3. 玩家通过多轮人生模拟，是否真的能比普通问卷更好地认识自己的偏好和边界。
4. 是否能够建立一个既不刻板、又足够简单的“人物 → 生活 → 互动 → 体验”模拟机制。
5. 如何让玩家校准出自己的峰谷，而不是最后收敛成所有属性都中等。
