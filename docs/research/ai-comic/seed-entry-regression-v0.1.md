# Early 15 Seed Regression v0.1｜旧 15 个入口在完整研究后的回归

> 状态：Research Complete / Pilot Input  
> 目的：检查前期凭直觉选出的 15 个用户语言入口，在 Person / Scene / Need-Fit 全量研究以后是否仍然成立。  
> 重要：这里判断的是“是否适合作为内容入口”，不是“是不是最重要的人格特质”。

## 1. 总结

回归结果：

~~~text
15 个 Seed
├─ 14 个：保留为 User-language Entry
└─ 1 个：保留，但必须明确内部拆分，不作为单一 Canonical Feature
~~~

没有一个需要直接删除。

这说明前期直觉并非主要问题。

真正的问题是：

> **我们过早把“用户会说的词”当成了“底层分类和优先级”。**

完整研究以后，这 15 个更适合成为第一批 Pilot Entry：它们负责让用户一眼进入；后台继续映射到多个 Canonical Concept、Scene 和 Need / Fit。

# 3. 为什么“顾家”和“家庭观念强”都保留

两者在用户语言里相近，但研究后边界不同：

~~~text
家庭观念强
→ 更偏 Value / Family Model
→ 他认为什么叫家庭、结不结婚、要不要孩子、父母应该介入多少

顾家
→ 更偏 Resource Allocation / Relationship Process
→ 他实际上把多少时间、钱、劳动和注意力投进家庭
~~~

一个人可以：

- 口头非常重家庭，但实际家务育儿投入低；
- 不喜欢传统“家庭观念”表达，但实际承担很多小家庭责任。

这个区别本身就是高价值内容。

---

# 4. “强势”暴露了 Canonical Model 的一个缺口

当前已有：

- 决策能力；
- 公平合作；
- 边界尊重；
- 自主价值。

但“强势”还经常指：

> **在共同决策里谁默认拥有更大决定权，以及一个人怎样使用影响力 / 控制权。**

这不是简单等同：

- 会做决定；
- 不公平；
- 不尊重边界。

因此本轮新增候选 Canonical Concept：

> **决策主导 / 控制方式（Decision Dominance / Control Style, working label）**

它需要在不同场景看：

- 高风险 / 高责任事情是否主动主导；
- 低风险事情是否也要控制；
- 对方不同意时是否允许真实协商；
- 自己判断错误后是否能交还决定权；
- 是否把“我负责”变成“只能听我的”。

这是由 Seed Regression 暴露的真实模型缺口，不是为了让分类更漂亮。

---

# 5. 回归后的定位

这 15 个入口现在统一定义为：

> **Pilot User-language Entry Set v0.1**

它们不是：

- Top 15 人格；
- 最重要的 15 个择偶标准；
- 完整人物分类；
- 永久选题范围。

它们是：

> **第一批用来验证“用户语言 → Canonical Concepts → Scene → Need/Fit → Topic”生产链的入口组合。**

所以后续可以继续新增数十、数百个 User-language Entry，而底层仍复用同一套研究空间。
