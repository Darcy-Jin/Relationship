# AI 漫画研究 Round 1

## 研究目标

本轮不是研究单纯的 AI 绘图工具，而是研究：

> 如何利用 AI 漫画作为内容入口，验证“理解人、关系决策”方向，并沉淀未来游戏需要的人物、关系、场景模型。

核心链路：

```
关系洞察
 ↓
漫画表达
 ↓
用户反馈
 ↓
人物/关系模型
 ↓
决策游戏素材
```

---

# 一、外部案例观察

## 1. 漫画不是单纯内容，而是 IP 和关系资产入口

以 WEBTOON 为代表的数字漫画平台，已经形成“内容 → 用户 → 商业化 → IP 扩展”的模式。

可观察到：

- 漫画可以作为长期内容资产；
- 角色和故事可以进一步扩展到影视、游戏、商品等方向；
- 内容生产和用户反馈本身就是资产积累过程。

参考：WEBTOON 提供广告分成、付费内容、粉丝支持等创作者商业化方式，并支持作品向影视、游戏等方向扩展。

# 二、对我们的启发

我们不应该做普通情感鸡汤漫画。

原因：

普通情感内容通常是：

```
给观点
 ↓
告诉用户答案
```

而我们的方向应该是：

```
展示一个人的选择
 ↓
展示背后的心理和长期影响
 ↓
让用户自己判断
```

这和未来关系决策游戏一致。

# 三、第一版内容机制模型

## 机制1：表象 vs 真实

模板：

```
你以为：
某个特点代表优势

实际上：
长期关系中可能带来另一种问题
```

例：

你以为：
脾气好的人一定容易相处。

实际上：
有些人只是避免表达冲突，问题可能长期积累。

---

## 机制2：短期吸引 vs 长期相处

模板：

```
恋爱阶段看到的是优点

长期生活暴露的是运行方式
```

---

## 机制3：双方视角差异

模板：

```
A认为：我是在付出

B感受到：我被控制/忽视
```

关系问题很多不是谁对谁错，而是双方模型不同。

---

## 机制4：优点背后的代价

模板：

```
优点
 ↓
极端情况下
 ↓
可能产生的问题
```

例如：

独立 → 不依赖别人 → 难以表达需求。

责任感强 → 承担很多 → 容易控制别人。

# 四、漫画形式初步结论

当前适合验证的形式：

## 上下双格

原因：

- 信息密度高；
- 用户一眼理解；
- 适合移动端浏览；
- 天然适合制造认知反差。

核心结构：

```
上：用户已有认知

下：隐藏事实/长期结果
```

# 五、未来需要建立的资产

## 1. 人物模型库

字段：

- 性格特点
- 核心需求
- 优势
- 风险
- 关系表现
- 常见冲突

---

## 2. 关系场景库

例如：

- 买房
- 生孩子
- 财务管理
- 双方父母
- 工作压力
- 育儿分工

每个场景记录：

- 不同人的选择
- 背后的价值观
- 可能结果

---

## 3. 漫画模板库

第一批模板：

1. 你以为 vs 实际
2. 恋爱时 vs 结婚后
3. 优点 vs 隐藏代价
4. 两个人为什么互相吸引又互相伤害

# 六、当前阶段结论

AI 漫画不是最终产品。

它承担三个角色：

1. 内容传播入口；
2. 人物关系研究工具；
3. 游戏素材生产方式。

下一阶段继续研究：

- 哪些主题容易传播；
- 哪些表达容易产生共鸣；
- AI 漫画生产流程如何标准化；
- 如何把漫画内容转化为游戏事件。
