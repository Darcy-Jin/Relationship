## 这 13 个维度怎么理解

~~~text
人物画风
=
画谁
×
怎么造型
×
怎么表演
×
怎么画出来
~~~

### A. 画谁

只决定角色载体。

例如：

> 人类

它不等于写实，也不等于真人照片感。

### B. 怎么造型

决定“这个人长成什么视觉形”。

这里最容易被混在一起，所以正式拆开：

~~~text
风格家族
≠
形状语言
≠
人体比例
≠
写实程度
≠
脸部语言
~~~

例如：

> 日系少女漫画 + 圆润形状 + 4.5 头身 + 轻漫画化 + 大眼简鼻

才是一个相对完整的人物造型描述。

### C. 怎么表演

脸和身体分开。

同一个人物设计：

- 可以用很克制的表情；
- 也可以突然用很夸张的漫画表情。

姿势也是独立的：

- 站得很自然；
- 缩成一团；
- 张开双臂；
- 整个人夸张地扑出去；

会直接改变内容的娱乐感和“包袱”力度。

### D. 怎么画出来

即使人物造型完全相同，只改变：

- 线；
- 颜色；
- 阴影；
- 纸张 / 笔触；
- 细节；

也会变成完全不同的画风。

因此正式把：

~~~text
线条
上色
明暗
材质
细节
~~~

拆开。

## 哪些东西明确不属于“人物画风”

下面这些继续单独管理，不塞进这 13 个维度：

| 内容 | 属于什么 |
|---|---|
| 温暖 / 治愈 / 冷幽默 / 讽刺 | 内容与情绪气质 |
| 都市 / 家庭 / 公司 / 校园 | 场景与美术方向 |
| 原创 IP / 固定女主 | 角色运营与连续性 |
| 背景复杂度 | 场景设计 |
| 构图 / 镜头 / 留白 | 画面与版式 |
| 人物一致性 | AI 生产约束 |
| 小红书 3:4 | 发布与版式规格 |

## 为什么新增这些维度

外部角色设计实践反复把下面几类问题分开：

- **Silhouette / Shape Language**：清晰轮廓和形状会直接影响人物是否一眼可读；
- **Pose / Gesture**：姿态和动作本身承担性格和情绪表达；
- **Expression**：脸部表达通常单独做 expression sheet；
- **Costume / Props**：属于角色具体造型信息，但不是“画风”核心轴；
- **Line / Color / Lighting / Material / Texture**：进入最终绘制时分别决定轮廓、体积和表面质感。

因此当前 13 维不是为了追求完整学术 taxonomy，而是为了：

> **以后试画时，可以明确知道“我们到底改了哪一件事”。**

## 当前使用方式

不要一次填满 13 个维度再开始画。

实际比较时：

1. 先固定脚本和角色；
2. 一次只改变 1～3 个关键维度；
3. 用同一页内容试画；
4. 看目标女性用户的代入、扫读、娱乐感和审美偏好；
5. 再逐步冻结真正有影响的维度。
