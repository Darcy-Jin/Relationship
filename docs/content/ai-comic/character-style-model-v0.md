## Relationship 当前约束

当前第一版主要服务：

- 小红书；
- 3:4 竖图；
- 女性读者；
- 关系 / 婚恋轻漫画；
- 少文字、扫一眼能懂；
- 娱乐优先，不做知识海报；
- 男女主底层 Person Identity 长期固定为用户本人 + 用户妻子；不同篇允许扮演不同 Story Role。

---

## 当前边界：固定的是 Person Identity，不是 Story Role

当前男女主长期真人原型已经固定：

- 男主 → 用户本人；
- 女主 → 用户妻子。

但这不等于每篇漫画都是现实中的同一对夫妻。

正式关系：

~~~text
固定
= Person Identity

可变
= Story Role
+ Role Transformation
+ Appearance State
+ Episode Scene
~~~

因此人物画风测试必须区分：

> **是在测试 Character Style，还是在测试某个 Story Role。**

测试画风时不要同时大改 Story Role。

## 当前第一优先参考方向

用户提供的小红书参考图目前只作为**风格参考**，不复制其中具体人物。

原来提取出的“轻 Q + 大眼 + 娃娃感”对普通泛角色可以成立，但现在男女主底层 Person Identity 已经固定为真人，因此需要增加一个更重要的约束：

> **漫画化可以简化，但不能用统一的大眼 / 娃娃脸模板覆盖真人识别结构。**

所以当前第一候选升级为：

### F2｜Identity-safe 轻手绘都市漫画

~~~text
角色载体
人类

风格家族
清新手绘漫画 / 都市生活插画

形状语言
柔和、自然，但不强行圆润化真人骨相

人体比例
轻夸张，约 5.5～6.5 头身
避免明显幼态 Q 版

写实—抽象程度
轻漫画化
保留真人头脸比例和关键识别关系

脸部语言
简化五官细节
但保留本人眼距、眼型、鼻嘴关系、脸型和轮廓
不统一放大眼睛，不做娃娃脸模板

表情语言
自然生活表情 + 适度漫画强化
不靠夸张变脸表达情绪

姿态动作
自然生活动作 + 少量 Gesture 强化

线条
铅笔感 / 手绘细线

上色
低饱和淡彩 / 轻水彩感

明暗
很轻，只保留必要体积

材质
纸张 / 铅笔 / 淡彩质感

细节
低到中等
靠简化和留白保持轻
~~~

这一版仍然只是当前第一候选，不是最终锁定画风。

## 当前明确不要

- 不复制参考图里的具体人物长相；
- 不直接复刻现成 IP；
- 不因为“更漂亮”就把人物改成另一种角色；
- 不把场景、构图、平台比例混进人物画风本身；
- 不在一轮 A/B 里同时大改角色、姿势、场景和画风。

## 当前验证方式

继续使用第一篇：

> **《互联网大厂男友：高薪，但没时间》**

做受控试画。

比较时优先固定：

- 同一人物设定；
- 同一服装；
- 同一姿势；
- 同一场景；
- 同一构图；
- 同一文字；
- 同一 3:4 比例。

每轮只改少量画风变量。

第一阶段看：

- 女性用户是否愿意看；
- 是否一眼看懂；
- 人物是否有代入感；
- 轻松感是否够；
- 连续 5 页能否保持一致；
- AI 生成是否稳定；
- 是否容易形成账号自己的视觉记忆。


## 下一轮正式只比较 3 个候选

现在不再比较 A～F 六大类。

为了提高信息量，下一轮只保留三个差异足够明显、又都能服务 Relationship 的 Character Style：

### Candidate A｜F2 轻手绘都市漫画

~~~text
轻漫画化
+ 5.5～6.5 头身
+ 手绘细线
+ 低饱和淡彩
+ 很轻明暗
+ 纸张 / 铅笔感
+ 身份保真优先
~~~

看什么：

> 是否最适合女性向关系内容，同时还能稳定保留你和老婆的真人识别度。

### Candidate B｜清爽都市线稿平涂

~~~text
漫画化
+ 约 6～6.5 头身
+ 干净细线
+ 柔和平涂
+ 简单阴影
+ 数字干净质感
+ 身份保真优先
~~~

看什么：

> 是否比手绘方案更清楚、更稳定、更适合长期批量生产。

### Candidate C｜轻半写实生活插画

~~~text
半写实
+ 接近正常成人比例
+ 弱描边 / 无明显描边
+ 低饱和柔和体积
+ 较真实五官
+ 中等细节
+ 身份保真优先
~~~

看什么：

> 是否更像真人、更有生活质感，但又不会太像写真、降低漫画效率和娱乐感。

### 本轮固定变量

三套候选必须固定：

- Person Identity：同一位真人；
- Story Role：不变；
- Role Transformation：不变；
- 年龄 / 胖瘦 / 发型 / 穿搭：不变；
- 表情 / 姿势：不变；
- 场景 / 构图 / 镜头：不变；
- 文字：不变；
- 3:4 比例：不变。

只比较 Character Style。

### 当前选择标准

第一轮不追求“最漂亮”。

优先判断：

1. 还是不是本人；
2. 女性读者是否愿意看；
3. 一眼能不能看懂人物和关系；
4. 连续 5 页能不能稳定；
5. AI 是否容易生产；
6. 连续几十篇是否耐看。

一旦选出当前最好方案：

> **冻结为 Relationship Character Style v1 / Locked for Production。**

后续 Episode 不再每页重新决定人物画风。
