# 2. 首批 15

## 01｜大厂 / 高强度职业：高薪，但没时间

核心问题：

> 高薪和平台很好，但恋爱里的共同时间会变成什么？

主要覆盖：

- Person：职业 / 工作方式；
- Scene：恋爱 × 工作 × 工作时间突变；
- Need：陪伴；
- Reframe：如果双方都需要大量个人空间，意义会变化。

当前 Episode 001 已经是这个方向的第一版。

---

## 02｜事业心强：平时忙没关系，孩子真正需要人时呢？

核心问题：

> 我介意的是你忙，还是需要共同承担时你仍然把工作放第一？

主要覆盖：

- 事业优先级；
- 婴幼儿照护；
- 工作时间突变；
- 公平 / 可靠 / 合作；
- 成长与家庭责任的 Trade-off。

---

## 03｜有房：你要的是“房”，还是一种稳定的居住生活？

核心问题：

> 有房当然有价值，但房贷、城市和未来迁移一起进入生活以后，我真正要的是什么？

主要覆盖：

- 现实硬条件；
- 房 / 居住；
- 大额财务事件；
- 经济安全；
- 未来方向。

这是第一批里专门保留的一条 **Selection Proxy** 内容，用来验证“硬条件 → 真实生活”的表达。

---

# 3. 后备 15

这些已经通过 Topic Gate，但暂时放在第二批：

1. 工作稳定：稳定很好，面对真正事业机会时呢？
2. 会赚钱：大额共同支出时怎样一起决定？
3. 家庭条件好：父母资源什么时候也会变成介入？
4. 本地人 / 城市稳定：事业换城市时谁跟谁走？
5. 父母同城 / 能帮带娃：轻松与边界怎么同时存在？
6. 随性 / 计划性低：自由还是不可预测？
7. 会沟通 / 会共情：父母冲突时到底怎么做？
8. 会道歉 / 会修复：同一个问题下一次还会不会回来？
9. 体贴 / 情绪价值：是真的理解，还是只会说好听的话？
10. 边界感：尊重父母和尊重伴侣冲突时怎么画线？
11. 专一 / 忠诚：不是没有异性朋友，而是如何执行边界。
12. 高收入：怀孕后收入突变时，你真正需要什么安全？
13. 出差 / 轮班 / 996：这种职业方式进入带娃以后是什么样？
14. 性与忠诚边界：你们说的“专一”真的是一回事吗？
15. 愿意改 / 会反思：他说会改，和半年后真的形成新习惯是两回事。

# 4. 为什么首批不是简单按“最热门”排

首批 Portfolio 同时要覆盖：

- 硬条件 → 真实生活；
- 事业与工作；
- 钱；
- 家庭 / 父母；
- 自主 / 社交；
- 生活习惯；
- 情绪 / 沟通；
- 关系过程；
- 婚育方向；
- 家务 / Mental Load。

并同时覆盖：

- 恋爱；
- 稳定交往；
- 同居；
- 婚后；
- 育儿；
- 中年；
- Crisis。

如果只按“热门标签”选，很容易变成：

> 大厂 / 有钱 / 老实 / 情绪稳定 / 顾家……

但共同生活里的真正内容空间会被压扁。

# 5. 原来的 15 个 Seed 怎么样了

原来的 Seed 没有白做。

研究后大部分仍然证明是有价值的用户入口，例如：

- 大厂 / 高收入；
- 事业心强；
- 情绪稳定；
- 顾家；
- 独立；
- 自律；
- 节俭；
- 爱社交；
- 孝顺。

但也出现了变化：

### 被拆开

例如：

> “靠谱 / 有责任感”

不再只是一个标签，而会拆到：

- 承诺执行；
- 危机可靠；
- 公平承担；
- 支持照护。

### 有些没有进入首批

例如：

- 强势；
- 工作稳定；

不是它们不重要，而是当前 Portfolio 已经有更强的场景覆盖，先放到后备 / 后续 Topic Pool。

### 新出现

研究以后有些原来没被放进 15 个 Seed 的内容反而值得首批测试：

- 有房到底代理什么；
- 作息差异；
- 要不要孩子的方向冲突；
- Mental Load。

这说明这轮 Research 确实改变了结果，而不是把原来的 15 个重新包装一遍。
