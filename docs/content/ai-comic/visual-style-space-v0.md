## 1. 当前选择要服务什么

当前 AI 漫画已经确认：

- 第一版主要面向女性读者；
- 内容不是知识科普，而是娱乐中带一点关系洞察；
- 每格文字少，要让人扫一眼就懂；
- 两页一个小章节：先给熟悉判断，再换一种需要 / 视角把它翻过来；
- 第一篇是《互联网大厂男友：高薪，但没时间》；
- 第一版角色载体暂定真实普通人类，不先用明星 / 现成 IP / 动物拟人做主线。

因此视觉选择首先服务：

> **代入快、关系一眼看懂、轻松不说教、能连续生产、人物能保持一致。**

不是单纯追求“画得最漂亮”。

## 1.1 前置规则：先定角色，再选画风

2026-09-25 进一步确认：

> **角色设定和画风是两件事。**

角色设定回答：

- 这个人是什么性格；
- 现实中长什么样；
- 身材、皮肤、发型怎样；
- 平时怎么穿；
- 收拾前后有什么变化。

画风回答：

> **用什么视觉语言把同一个人表现出来。**

同一个角色可以被画成日系、美式、韩漫、简笔、半写实等不同方向。

但画风不是中性的。

它会放大人物已有特质，例如：

- 柔和细腻的画法容易放大温柔、可爱、细腻；
- 强轮廓和成熟造型容易放大自信、性感、都市感；
- 高精细、柔光、长卷发等组合容易把普通人物自动推向“理想化美女”。

因此正式比较画风前，必须先固定角色。

当前女性代入角色的视觉基线是：

> **普通、真实、有轻微不完美；靠妆容、发型、穿搭和精神状态变得更好看，而不是天生大美女。**

后续做画风对比时：

> **只改变画风，不改变人物本身。**

尽量保持同一：

- 脸型；
- 五官比例；
- 发型长度与基本形态；
- 身材；
- 年龄感；
- 穿搭；
- 妆容强度；
- 姿势 / 场景。

这样比较出来的才是：

> **画风差异。**

而不是：

> “这一版人物本身更漂亮，所以看起来更好。”

## 2. 视觉风格不要当成一个变量

当前至少拆成下面 10 个因素。

### A. 角色载体

候选：

1. 普通真人类；
2. Q 版 / chibi 人类；
3. 动物拟人；
4. 抽象 / 符号化人物；
5. 固定原创 IP。

第一版默认从普通真人类开始，但其他选项保留为对标。

### B. 写实程度

候选：

1. 极简符号；
2. 简笔漫画；
3. 卡通；
4. 半写实插画；
5. 高写实 / 接近照片。

越写实：
- 真实生活感通常越强；
- AI 人物一致性和表情自然度要求越高；
- 画面更容易喧宾夺主。

### C. 人物比例 / 造型

候选：

1. 正常人体比例；
2. 轻微夸张；
3. 大头小身；
4. 明显 Q 版；
5. 漫画式夸张表情。

它决定内容更偏：
- 真实生活；
- 轻松娱乐；
- 段子 / 表情包。

### D. 情绪气质

候选：

1. 温暖；
2. 轻松；
3. 可爱；
4. 冷幽默；
5. 讽刺；
6. 都市感；
7. 治愈；
8. 克制 / 冷静；
9. 戏剧化。

Relationship 第一版不希望太“老师”，所以轻松、都市、冷幽默值得优先测试。

### E. 线条

候选：

1. 无明显描边；
2. 细线；
3. 手绘感；
4. 粗线漫画；
5. 草稿 / 涂鸦感。

### F. 色彩

候选：

1. 黑白；
2. 黑白 + 单一强调色；
3. 低饱和；
4. 柔和 / 粉彩；
5. 明亮平涂；
6. 高饱和强对比；
7. 半写实光影。

### G. 场景复杂度

候选：

1. 几乎无背景；
2. 一个关键道具；
3. 简化生活场景；
4. 完整生活场景；
5. 电影式丰富环境。

我们的关系内容往往需要“床、餐桌、公司、手机、两个人的距离”等环境信息，因此过度无背景可能损失表达。

### H. 构图重点

候选：

1. 人物大特写；
2. 半身人物 + 动作；
3. 双人关系构图；
4. 人物 + 环境；
5. 环境主导 / 人物很小；
6. 隐喻式构图。

不同页可以变化，不要求整篇只有一种构图。

### I. 文字进入画面的方式

候选：

1. 对话气泡；
2. 顶部 / 底部短字幕；
3. 旁白框；
4. 手机消息 / UI；
5. 直接把字融进环境；
6. 几种混用。

当前原则：

> 能演出来的不解释；文字只保留关键信息。

### J. 人物连续性 / IP 强度

候选：

1. 每篇新人物；
2. 同一篇一致，不同篇变化；
3. 固定女主，男方按题变化；
4. 固定男女主；
5. 完整原创 IP 群像。

第一版当前暂定：

> 同一篇人物一致，不同篇可以变化。

## 3. 除了“好不好看”，还要用这些标准筛

每套组合都看：

1. **目标用户代入感**：女性读者会不会觉得这是“我的生活”；
2. **扫读速度**：一眼能不能看懂；
3. **关系表达力**：能不能看出“谁在等、谁在忙、谁在享受自己的时间”；
4. **娱乐感**：是不是轻松，而不是知识海报；
5. **最后一下的力度**：反转 / 换视角时画面能不能明显变；
6. **人物一致性**：同一篇 5 页能不能稳定；
7. **AI 可生产性**：是不是经常需要大量返工；
8. **文本容纳**：少量字幕和对白能否自然放进去；
9. **账号识别度**：以后能不能形成自己的视觉记忆；
10. **长期耐看**：连续发几十篇会不会审美疲劳。

## 4. 第一轮候选风格包

不是穷举所有笛卡尔组合，而是先组合成几套内部自洽的候选方案。

### 方案 A｜都市简洁漫画

~~~text
普通真人类
+ 卡通 / 轻半写实
+ 正常比例
+ 轻松都市感
+ 细线
+ 低饱和 / 柔和色
+ 简化真实生活场景
+ 双人关系构图 / 人物 + 环境
+ 短字幕 + 必要对白
+ 同篇固定人物
~~~

特点：

- 最接近当前内容目标；
- 容易表现真实生活；
- 不会太“幼”；
- 仍保留漫画娱乐感。

### 方案 B｜轻 Q 版都市情侣

~~~text
真人类
+ 卡通
+ 轻微大头 / 轻 Q
+ 可爱 + 冷幽默
+ 较粗线条
+ 明亮平涂
+ 简化场景
+ 人物动作 / 表情主导
+ 气泡对白
+ 同篇固定人物
~~~

特点：

- 娱乐感强；
- 包袱容易响；
- 关系议题容易变轻；
- 但有可能削弱“真实生活”的代入。

### 方案 C｜半写实生活插画

~~~text
真人类
+ 半写实
+ 正常比例
+ 都市 / 温暖 / 克制
+ 弱描边
+ 低饱和半写实光影
+ 完整生活场景
+ 人物 + 环境
+ 极少字幕
+ 同篇固定人物
~~~

特点：

- 真实感和女性向审美可能更强；
- 适合孤独、陪伴、生活距离这些情绪；
- AI 人物一致性和生产成本更高；
- 太漂亮时可能削弱段子感。

### 方案 D｜极简冷幽默

~~~text
真人类
+ 简笔
+ 正常 / 轻夸张比例
+ 冷幽默
+ 简单线条
+ 黑白 + 单一强调色
+ 一个关键场景 / 道具
+ 留白多
+ 极短字幕
+ 同篇固定人物
~~~

特点：

- 信息效率高；
- 很适合“翻一页来一下”；
- 账号辨识度容易建立；
- 对脚本要求高，画面不能靠细节补救。

### 方案 E｜编辑插画 / 隐喻型

~~~text
真人类
+ 抽象 / 半写实编辑插画
+ 正常比例
+ 克制 / 有设计感
+ 无明显描边
+ 有控制的配色
+ 现实场景 + 隐喻
+ 构图主导
+ 极少文字
+ 人物不必强 IP 化
~~~

特点：

- 最容易显得“高级”；
- 适合最后一页大收；
- 但每页都这么画会降低娱乐性和生产速度。

## 5. 一个重要可能：正文和“反转页”不必完全同一种构图

当前内容本身就有节奏变化：

~~~text
判断页
↓
翻页 / 换视角页
~~~

因此以后可以测试：

> **同一套视觉语言，但不同页面使用不同构图强度。**

例如：

- 判断页：简单双格 / 小场景；
- 换视角页：更完整的大场景；
- 最后互动页：更平面、更像海报。

这是“同一画风里的节奏变化”，不是每页换一个画风。

然后把外部案例映射回上面这些因素：

最后再从方案 A～E 中：

- 混合；

## 7. 第一轮选择原则

第一版不追求终局 IP。

优先选：

> **够好看 + 一眼看懂 + 能连续出图 + 人物稳定 + 不妨碍内容。**

先用《互联网大厂男友》同一份脚本试画 2～3 套候选风格。

用同一个内容比较，才看得出到底是画风差异，还是内容差异。

## 8. 当前第一优先参考风格（2026-09-25）

用户提供了一张小红书参考图，当前判断最接近：

> **轻手绘少女漫画风 / 清新简笔插画**

它不是高写实，也不是重 Q 版。

当前提取出的视觉特征：

~~~text
普通真人类
+ 轻 Q 化比例
+ 手绘 / 铅笔感线条
+ 低饱和浅色
+ 大量留白
+ 简化背景
+ 人物动作与表情主导
+ 少量文字
+ 轻松、柔和、女性向
~~~

重点不是复刻某一张图，而是借它确认：

- 人物不需要画得太精；
- 线条可以保留手绘感；
- 场景只保留最有用的信息；
- 画面要轻，不能像知识海报；
- 女性读者能快速代入；
- 适合“第一页判断 / 第二页换视角”的轻漫画节奏。

### 当前画面比例

用户提供的参考图实际尺寸：

`1147 × 1536`

宽高比约：

`0.747`

因此第一版统一按：

> **3:4 竖图**

进行设计和生成。

当前主要发布平台是小红书，所以后续所有首轮试画默认先按 3:4 竖图制作。

这张参考不完全等于原 A～E 中任何一套。

更接近：

> **A 都市简洁漫画 + B 轻 Q + D 极简留白**

但需要单独抽成新的候选方向：

### 方案 F｜轻手绘少女漫画

~~~text
普通真人类
+ 轻 Q 化
+ 手绘 / 铅笔感细线
+ 低饱和浅色
+ 白底 / 大留白
+ 简化生活场景

~~~

当前优先级：
