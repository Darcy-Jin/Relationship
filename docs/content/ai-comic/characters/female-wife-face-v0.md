## 1.1 参考照片怎么使用：跨年龄验证同一个身份，不是“年轻版 / 现在版”

2026-09-25 用户明确修正：

> **新增的年轻时期照片不是为了定义“年轻时更可爱”的另一个状态，而是为了提供更多证据，说明她一直就是这样的头脸结构和气质。**

因此当前所有照片应理解为：

~~~text
不同年龄
+
不同发型 / 妆容 / 光线 / 镜头
+
同一个人
↓
共同提取跨时间稳定的身份特征
~~~

年轻照片和现在照片不是两个角色版本，也不是“年轻时的可爱特征”和“现在的成熟特征”分别建模。

它们共同用于确认这些**跨年龄稳定**的身份特征：

- 头脸纵向偏长；
- 头顶和额头圆润、有宽度；
- 下颌转折柔和，不形成尖角；
- 下巴圆润，不是尖下巴；
- 颧骨有存在感；
- 鼻侧 / 眼下苹果肌有体积；
- 颧骨下方到下颌前段有一点自然软组织 / 轻微婴儿肥；
- 五官在较长头脸上显得相对集中；
- 整体亲切、可爱、灵动，而不是美型、冷艳、锐利。

一句话：

> **这些不是“年轻态特征”，而是她这个人长期稳定的脸部身份结构。**

唯一需要单独按时间处理的当前已知变化：

> **眼皮状态发生过真实改变。**

早期照片以单眼皮为主；之后做过双眼皮，因此后期照片可以出现双眼皮。

这属于：

> **同一个人的真实时间变化，不是身份漂移。**

## 3. 第一优先级：头脸整体比例

### 3.1 先分清：头长、脸长，不等于脸宽或下巴尖

2026-09-25 连续试画后，用户进一步明确：

> **她的头脸整体是纵向偏长，但头顶和下巴都很圆润。**

之前两种错误都要避免：

- 为了“长”把下巴拉尖；
- 为了“可爱 / 婴儿肥”把整张脸横向加宽，画胖。

正确方向是：

> **纵向更长 + 横向中等 + 头顶圆润偏宽 + 下巴圆润。**

也就是说：

- 脸不是短圆；
- 也不是窄尖；
- 是较长的鹅蛋型 / 长椭圆，但两端都柔和、圆润；
- 颧骨以下可以慢慢收，但不能快速削成 V。

### 3.2 头顶与额头：比前几版更宽、更圆

当前要明确修正：

- 头顶不能尖、不能像小山峰；
- 头顶部轮廓是比较完整的圆弧；
- 额头和太阳穴区域比前几版要宽一点；
- 额头宽度和颧骨区宽度相对接近，不要上窄下宽；
- 发型可以变化，但不能靠头发把头顶收尖。

一句话：

> **上半个头是圆而有宽度的，不是尖顶。**

### 3.3 脸长与五官“集中感”

用户指出一个很重要的识别感：

> **因为整个头脸偏长，眼、鼻、嘴反而显得更集中在脸中间。**

这不是把五官真的挤成一团，而是保持：

- 头顶 / 额头有足够纵向空间；
- 下巴 / 下半脸也有足够纵向空间；
- 眼、鼻、嘴之间的距离不要被“拉长脸”一起等比例拉开；
- 五官整体在脸中央形成较紧凑的视觉组团。

这会带来本人比较明显的：

> **可爱、亲切、稍带幼态的感觉。**

后续不能只复制单个五官，必须检查：

> **五官在整张长脸上的相对位置。**

### 3.4 原图比例校准（近似参考，不作为生物测量）

以当前最接近正面的无眼镜生活照为主参考，受镜头和表情影响，仅用于生成约束：

- 头顶到下巴的整体纵向长度，约为最大脸宽的 **1.35～1.40 倍**；
- 发际线到下巴的可见脸长，约为最大脸宽的 **1.18～1.25 倍**；
- 额头 / 太阳穴区域不要明显窄于颧骨区；
- 颧骨区是主要横向支撑点；
- 下颌宽度小于颧骨宽度，但差值不能大到形成尖 V；
- 眼睛到嘴巴的主要五官区域，只占整个“头顶到下巴”纵向高度的大约三分之一上下，因此视觉上会觉得五官相对集中。

这些比例的目的不是追求毫米级复刻，而是防止生成模型：

> **把“长脸”误解成“窄脸 + 尖下巴 + 五官拉开”。**

### 3.5 下巴

下巴必须保持：

- 圆润；
- 柔和；
- 不长出尖点；
- 有一点自然肉感；
- 和长脸并存。

正确感觉：

> **脸是长的，但下巴是圆的。**

错误方向：

> 只要脸长，就自动画成尖下巴。

## 4. 第一优先级：颧骨 + 苹果肌 + 轻微婴儿肥

这一部分是目前“像不像”和“亲不亲切”的关键。

### 4.1 颧骨

她的颧骨比前几版试画都要更有存在感。

需要保留：

- 颧骨位置比较清楚；
- 中脸有真实的立体支撑；
- 不能把鼻子两侧到眼下这一片画成平面；
- 但颧骨不是尖锐、外扩、凌厉型。

正确感觉：

> **有骨点、有立体感，但仍然柔和。**

### 4.2 苹果肌

苹果肌主要在：

> **鼻子两侧、眼下、颧骨前方的面中区域。**

需要保留：

- 静态就有一点自然饱满；
- 微笑时明显向上、向外鼓起；
- 会顶起下眼睑，让眼睛也参与笑；
- 和颧骨一起形成真实面部起伏；
- 不能只给脸颊涂一点红就算苹果肌。

### 4.3 颧骨下方 / 下巴两侧：局部轻微婴儿肥

用户进一步指出：

> **她在颧骨下方、下巴旁边有一点柔软的婴儿肥感。**

这里要非常精确：

- 是局部软组织，不是把整张脸加宽；
- 位置主要在颧骨下方到下颌前段；
- 会让下半脸更柔软、更可爱；
- 但脸整体仍然偏长；
- 下颌仍然是缓慢收束，不是方脸，也不是胖圆脸。

所以：

> **婴儿肥 = 局部软，不等于脸宽。**

这也是前一版“画胖了”的主要原因：

> 把局部肉感错误地变成了整张脸横向变宽。

## 5. 第一优先级：眼睛

眼睛的**稳定身份特征**和**真实时间变化**要分开。

### 5.1 稳定身份特征

无论单眼皮还是后来做过双眼皮，优先保持：

- 眼型自然偏细长；
- 眼睛大小正常偏克制；
- 眼距和眉眼关系保持本人比例；
- 不做少女漫画式大眼；
- 不用放大眼睛来制造“有神”或“好看”；
- 笑时眼睛会自然弯、自然变窄，并参与整张脸的笑。

### 5.2 真实时间变化：单眼皮 → 双眼皮

用户补充：

> **她原来是单眼皮，后来做过双眼皮。**

因此不能再把“单眼皮”写成永久不变的身份锚点。

正确规则：

- 画年轻 / 早期状态时，可按原始单眼皮参考；
- 画现在 / 后期状态时，可按后期真实双眼皮参考；
- 不管是哪一时期，都不能把眼睛自动放大成模板动漫眼；
- 眼皮变化不能带动整套眉眼、脸型、气质一起被重新设计。

一句话：

> **眼皮可以随真实时间变化，眼睛是谁不能变。**

## 6. 第二优先级：其他五官

当前照片足以说明整体身份，但这一阶段不对不确定的小细节过度下结论。

先遵守：

### 眉毛

- 保持自然；
- 不改成锋利、高挑、精修感很强的眉型；
- 眉毛服务真实眉眼关系，不单独“美化”。

### 鼻子

- 保持真实比例；
- 不主动拔高鼻梁；
- 不改成窄、高、挺的模板鼻；
- 不因为半写实画风增加欧美式立体感。

### 嘴

连续试画后修正：

- 嘴不能画得太小；
- 嘴部横向宽度要保留本人自然比例；
- 唇厚自然，不主动丰唇；
- 不使用精致红唇 / 网红唇形替代本人结构；
- 笑起来时嘴角上扬幅度不能只发生在嘴本身，要带动整张脸。

尤其注意：

> **嘴太小，会让中下脸显得更尖、更拘谨，也会削弱本人真实的亲和感。**

## 7. 动态身份：笑容必须是“整张脸一起笑”，并保留她自己的灵气

连续试画暴露了一个稳定问题：

> **只把嘴角抬起来，会形成很假的笑。**

本人真实笑容不是“嘴在笑，脸没动”，而是：

- 颧骨抬高；
- 苹果肌明显上提；
- 鼻子两侧和眼下的面中体积一起变化；
- 下眼睑被苹果肌轻微顶起；
- 外眼角参与；
- 单眼皮状态下，眼睛会自然弯、自然变窄；
- 眼神仍然有光、有回应；
- 嘴角自然上扬；
- 嘴角向下到下巴附近，会出现非常细、自然的牵拉线 / 表情线；
- 下半脸也会因为笑容出现轻微提拉，不是静止不动。

因此要把笑容理解成：

> **眼睛 + 颧骨 + 苹果肌 + 嘴 + 下半脸一起发生的动作。**

### 笑容禁止项

不要：

- 只拉嘴角；
- 眼睛完全不动；
- 苹果肌不起来；
- 颧骨仍停留在平静位置；
- 眼睛画大来假装“开心”；
- 笑时仍是一张平脸；
- 把嘴角到下巴的自然表情线全部磨掉；
- 做商业证件照式假笑。

验收时先问：

> **不看嘴，只看眼睛和面中，能不能看出她在笑？**

如果不能：

> **这张笑脸就不通过。**

### 7.1 她的笑不是标准甜笑

用户对本人长期神态的描述是：

> **笑起来会有一点“邪邪的”感觉，古灵精怪，很有主意、很有主见、很有想法。**

这里不是把她画成坏、冷或攻击性强。

更准确的视觉方向是：

- 嘴角不是完全对称、标准化的“营业微笑”；
- 可以有一点轻微偏嘴角 / 若有所思的笑意；
- 眼神有主意、有回应，不是空洞甜笑；
- 表情里有一点小机灵、小调皮；
- 看起来像“她自己心里有想法”，而不是只是在配合镜头；
- 亲切和灵动同时存在。

因此当前目标不是：

> **漂亮的标准女主笑。**

而是：

> **温柔可爱 + 有灵气 + 有一点古灵精怪的本人笑。**

## 8. 不锁死的外观变量

下面这些不是身份本身：

- 发型；
- 扎发 / 披发；
- 刘海；
- 帽子；
- 眼镜；
- 妆容；
- 穿搭；
- 胖瘦；
- 皮肤状态；
- 精神状态；
- 年龄阶段；
- 当前故事里的职业和生活状态。

其中：

> **眼镜尤其不能作为“认出她”的必要条件。**

后续必须能同时通过：

- 不戴眼镜；
- 戴眼镜；

两种状态认出是同一个人。

## 9. 当前生成禁止项

后续试画优先检查以下错误：

1. 把“长脸”画成“窄脸 + 尖下巴”；
2. 为了婴儿肥把整张脸横向画胖；
3. 头顶画尖、画窄；
4. 额头 / 太阳穴区域过窄；
5. 五官随着长脸一起被上下拉散；
6. 下巴被画尖；
7. 脸被削成明显 V 型；
8. 颧骨被美化掉或画平；
9. 鼻子两侧的苹果肌被磨平；
10. 苹果肌只靠腮红表现，没有真实体积；
11. 颧骨下方的局部婴儿肥被误画成整张胖脸；
12. 不分时期把所有照片都强行统一成单眼皮或双眼皮；
13. 眼皮变化时顺带把眉眼关系、眼睛大小和脸型一起改掉；
14. 眼睛被放大；
15. 嘴画得过小；
16. 笑容只动嘴，不动眼睛、苹果肌和颧骨；
17. 嘴角到下巴的自然细表情线被全部磨掉；
18. 把她的灵动 / 古灵精怪画成标准甜妹笑；
19. 五官被统一成模板美女；
20. 为了“更漂亮”改变本人头脸结构；
21. 不同画风实际偷偷换了不同的脸。

## 10. 下一轮正确的对比方式

不再直接做复杂 Character Sheet。

先做：

> **同一张真人原图 + 同一张脸的多画风翻译。**

版式优先：

~~~text
真人原图
│
├─ 简笔风
├─ 扁平卡通
├─ 日系漫画
├─ 手绘质感
├─ 半写实漫画
└─ Q 版
~~~

要求：

- 真人原图直接放在对比板里，不重新“生成一个真人版本”；
- 所有画风使用同一张参考图、同一角度、同一表情；
- 第一轮尽量不靠眼镜、服装、场景提高辨识度；
- 画风可以变，脸部身份结构不能跟着变；
- 先看“像不像”，再看“哪种画风好看”。

### 下一轮先评八件事

1. 头顶是不是够宽、够圆，而不是尖？
2. 头脸整体是不是纵向偏长，而不是变胖变宽？
3. 五官是不是集中在较长头脸的中部，而不是被上下拉散？
4. 下巴是不是圆润，而不是尖？
5. 颧骨和鼻子两侧的苹果肌有没有真实立体感？
6. 颧骨下方 / 下巴两侧有没有一点局部婴儿肥，但没有把脸画胖？
7. 是否按参考照片对应时期正确处理眼皮状态，同时保住原本眼型和眉眼关系？
8. 嘴巴真实大小、笑到眼睛、那一点灵动 / 古灵精怪有没有保住？
9. 不看文字标签，第一眼像不像本人？

如果结构不对：

> **先改脸，不讨论画风。**
