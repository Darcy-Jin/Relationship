## 1.1 参考照片怎么使用：结构基线与补充证据分开

2026-09-25 进一步校准：

> **所有照片都属于同一个人，但不同照片承担的用途不同。不能让某一张有明显角度或表情变形的照片，反过来定义她的静态脸型。**

当前正式分成两类参考：

### A. 结构基线：优先使用现在的照片

当前身份校准与后续重画，优先使用现在的：

- 正脸；
- 接近正脸；
- 自然表情；
- 自然微笑；
- 轻微 3/4。

它们主要决定：

- 头脸整体长宽关系；
- 头顶 / 额头宽度与圆润度；
- 颧骨与苹果肌的体积；
- 下颌收束；
- 下巴圆润度；
- 五官在整张脸上的相对位置；
- 现在的眼皮状态与眼神。

### B. 补充证据：年轻照片用于验证长期稳定特征与表情机制

年轻时期照片继续保留，而且非常重要。

但它们主要用于：

1. 验证很多脸部特征从年轻到现在一直稳定存在；
2. 补充现在照片不容易看清的表情变化；
3. 说明某些“变尖 / 变窄”的视觉效果来自角度或表情，而不是骨相本身。

例如：

> **年轻时期某些轻侧转 + 努嘴角的照片，会让下巴视觉上显得更尖。这个尖感是动态与角度造成的，不应该写回静态脸型基线。**

因此后续严格遵守：

> **现在照片定结构；年轻照片补充跨年龄验证与表情机制。**

不是：

> 用年轻侧转照片重新定义一张更尖的脸。

## 1.2 跨年龄稳定的身份特征

年轻照片与现在照片共同证明，以下特征长期稳定：

- 头脸纵向偏长；
- 头顶和额头圆润、有宽度；
- 下颌转折柔和，不形成尖角；
- 静态正面下巴圆润，不是尖下巴；
- 颧骨有存在感；
- 鼻侧 / 眼下苹果肌有体积；
- 颧骨下方到下颌前段有一点自然软组织 / 轻微婴儿肥；
- 五官在较长头脸上显得相对集中；
- 整体亲切、可爱、灵动，而不是美型、冷艳、锐利。

眼皮属于真实时间变化：

- 早期以单眼皮为主；
- 后期做过双眼皮。

这属于同一个人的真实变化，不是身份漂移。

## 3. 第一优先级：头脸整体比例

### 3.1 先分清：头长、脸长，不等于脸宽或下巴尖

2026-09-25 连续试画后，用户进一步明确：

> **她的头脸整体是纵向偏长，但头顶和下巴都很圆润。**

之前两种错误都要避免：

- 为了“长”把下巴拉尖；
- 为了“可爱 / 婴儿肥”把整张脸横向加宽，画胖。

正确方向是：

> **纵向更长 + 横向中等 + 头顶圆润偏宽 + 下巴圆润。**

也就是说：

- 脸不是短圆；
- 也不是窄尖；
- 是较长的鹅蛋型 / 长椭圆，但两端都柔和、圆润；
- 颧骨以下可以慢慢收，但不能快速削成 V。

### 3.2 头顶与额头：比前几版更宽、更圆

当前要明确修正：

- 头顶不能尖、不能像小山峰；
- 头顶部轮廓是比较完整的圆弧；
- 额头和太阳穴区域比前几版要宽一点；
- 额头宽度和颧骨区宽度相对接近，不要上窄下宽；
- 发型可以变化，但不能靠头发把头顶收尖。

一句话：

> **上半个头是圆而有宽度的，不是尖顶。**

### 3.3 脸长与五官“集中感”

用户指出一个很重要的识别感：

> **因为整个头脸偏长，眼、鼻、嘴反而显得更集中在脸中间。**

这不是把五官真的挤成一团，而是保持：

- 头顶 / 额头有足够纵向空间；
- 下巴 / 下半脸也有足够纵向空间；
- 眼、鼻、嘴之间的距离不要被“拉长脸”一起等比例拉开；
- 五官整体在脸中央形成较紧凑的视觉组团。

这会带来本人比较明显的：

> **可爱、亲切、稍带幼态的感觉。**

后续不能只复制单个五官，必须检查：

> **五官在整张长脸上的相对位置。**

### 3.4 原图比例校准（近似参考，不作为生物测量）

以当前最接近正面的无眼镜生活照为主参考，受镜头和表情影响，仅用于生成约束：

- 头顶到下巴的整体纵向长度，约为最大脸宽的 **1.35～1.40 倍**；
- 发际线到下巴的可见脸长，约为最大脸宽的 **1.18～1.25 倍**；
- 额头 / 太阳穴区域不要明显窄于颧骨区；
- 颧骨区是主要横向支撑点；
- 下颌宽度小于颧骨宽度，但差值不能大到形成尖 V；
- 眼睛到嘴巴的主要五官区域，只占整个“头顶到下巴”纵向高度的大约三分之一上下，因此视觉上会觉得五官相对集中。

这些比例的目的不是追求毫米级复刻，而是防止生成模型：

> **把“长脸”误解成“窄脸 + 尖下巴 + 五官拉开”。**

### 3.5 下巴

下巴必须保持：

- 圆润；
- 柔和；
- 不长出尖点；
- 有一点自然肉感；
- 和长脸并存。

正确感觉：

> **脸是长的，但下巴是圆的。**

错误方向：

> 只要脸长，就自动画成尖下巴。

### 3.6 3/4 与侧脸：不能把正脸“削尖”以后当成侧脸

当前身份校准板暴露出一个明显问题：

> **正脸已经接近方向，但一转到 3/4 / 侧脸，模型又自动把下颌和下巴画尖，婴儿肥也消失了。**

真实侧面应该继续保留正脸里的“柔软体积”，而不是换成另一种骨相。

#### 侧脸的正确结构

- 颧骨仍然有存在感，但不是锐利突出；
- 颧骨下方不能突然塌进去或形成明显凹面；
- 下颊到下颌前段仍然保留一点软组织 / 婴儿肥；
- 下颌角不是清晰尖角，而是被软组织包住的柔和转折；
- 从耳下 / 后颊到下巴的线，是一条缓慢、连续的弧线；
- 下巴末端短而圆润，不拉长，不向前形成尖点；
- 3/4 角度时，靠近镜头这一侧的脸颊不能被“收掉”，要保留真实宽度和体积；
- 不做明显“削骨感”“瓜子脸侧影”“美型漫画侧脸”。

一句话：

> **侧脸也要有肉、有弧度、有圆下巴，不能一侧过来就突然变成尖脸。**

#### 为什么现在会“不像”

当前生成的侧脸主要错在：

~~~text
颧骨以下收得太快
+
下颊软组织消失
+
下颌转折太利
+
下巴拉尖
↓
从“可爱、柔和”滑成“漂亮、美型”
~~~

真正的可爱感来自：

> **长一点的头脸 + 五官集中 + 软眼神 + 有体积的颧骨 / 苹果肌 + 下颊一点婴儿肥 + 圆润下巴。**

这些在正脸、3/4、侧脸都必须同时成立。

## 4. 第一优先级：颧骨 + 苹果肌 + 轻微婴儿肥

这一部分是目前“像不像”和“亲不亲切”的关键。

### 4.1 颧骨

她的颧骨比前几版试画都要更有存在感。

需要保留：

- 颧骨位置比较清楚；
- 中脸有真实的立体支撑；
- 不能把鼻子两侧到眼下这一片画成平面；
- 但颧骨不是尖锐、外扩、凌厉型。

正确感觉：

> **有骨点、有立体感，但仍然柔和。**

### 4.2 苹果肌

苹果肌主要在：

> **鼻子两侧、眼下、颧骨前方的面中区域。**

需要保留：

- 静态就有一点自然饱满；
- 微笑时明显向上、向外鼓起；
- 会顶起下眼睑，让眼睛也参与笑；
- 和颧骨一起形成真实面部起伏；
- 不能只给脸颊涂一点红就算苹果肌。

### 4.3 颧骨下方 / 下巴两侧：局部轻微婴儿肥

用户进一步指出：

> **她在颧骨下方、下巴旁边有一点柔软的婴儿肥感。**

这里要非常精确：

- 是局部软组织，不是把整张脸加宽；
- 位置主要在颧骨下方到下颌前段；
- 会让下半脸更柔软、更可爱；
- 但脸整体仍然偏长；
- 下颌仍然是缓慢收束，不是方脸，也不是胖圆脸。

所以：

> **婴儿肥 = 局部软，不等于脸宽。**

这也是前一版“画胖了”的主要原因：

> 把局部肉感错误地变成了整张脸横向变宽。

## 5. 第一优先级：眼睛

眼睛的**稳定身份特征**和**真实时间变化**要分开。

### 5.1 稳定身份特征

无论单眼皮还是后来做过双眼皮，优先保持：

- 眼型自然偏细长；
- 眼睛大小正常偏克制；
- 眼距和眉眼关系保持本人比例；
- 不做少女漫画式大眼；
- 不用放大眼睛来制造“有神”或“好看”；
- 笑时眼睛会自然弯、自然变窄，并参与整张脸的笑。

### 5.2 真实时间变化：单眼皮 → 双眼皮

用户补充：

> **她原来是单眼皮，后来做过双眼皮。**

因此不能再把“单眼皮”写成永久不变的身份锚点。

正确规则：

- 画年轻 / 早期状态时，可按原始单眼皮参考；
- 画现在 / 后期状态时，可按后期真实双眼皮参考；
- 不管是哪一时期，都不能把眼睛自动放大成模板动漫眼；
- 眼皮变化不能带动整套眉眼、脸型、气质一起被重新设计。

一句话：

> **眼皮可以随真实时间变化，眼睛是谁不能变。**

### 5.3 稳定的“朦胧感”：不是没精神，而是眼神不锋利

用户进一步指出：

> **她的眼神长期有一种“朦胧”的感觉，和用户本人那种更直接、更聚焦、更锐利的眼神不一样。**

这里的“朦胧”不是模糊、困倦、没精神，也不是把画面做虚焦。

从当前多张照片对比，更接近下面这组可见特征：

- 眼睛纵向开合度偏克制，不是睁得很圆；
- 上眼睑比较放松，虹膜上缘常被上眼皮自然盖住一点；
- 下方眼白露得少，不形成“瞪大眼睛”的感觉；
- 眼尾和下眼睑线条比较柔，不做锐利上挑；
- 眼神聚焦是有的，但不会形成很强的“盯人感”；
- 黑眼珠 / 眼白 / 高光之间的对比不要做得太硬；
- 即使有双眼皮，也不能把眼睛画成“睁得更大、更亮、更精致”的标准美女眼；
- 笑时眼睛进一步自然弯起，朦胧感和灵动感可以同时存在。

更准确的一句话：

> **眼神是软的、松的、带一点雾感，但不是空的。**

生成时不要用这些错误替代“朦胧”：

- 失焦；
- 呆；
- 困；
- 无神；
- 眼睛发灰；
- 故意虚化瞳孔。

真正要保留的是：

> **眼睑张力较低 + 眼白暴露少 + 轮廓柔和 + 聚焦不锋利。**

## 6. 第二优先级：其他五官

当前照片足以说明整体身份，但这一阶段不对不确定的小细节过度下结论。

先遵守：

### 眉毛

- 保持自然；
- 不改成锋利、高挑、精修感很强的眉型；
- 眉毛服务真实眉眼关系，不单独“美化”。

### 鼻子

- 保持真实比例；
- 不主动拔高鼻梁；
- 不改成窄、高、挺的模板鼻；
- 不因为半写实画风增加欧美式立体感。

### 嘴

连续试画后修正：

- 嘴不能画得太小；
- 嘴部横向宽度要保留本人自然比例；
- 唇厚自然，不主动丰唇；
- 不使用精致红唇 / 网红唇形替代本人结构；
- 笑起来时嘴角上扬幅度不能只发生在嘴本身，要带动整张脸。

尤其注意：

> **嘴太小，会让中下脸显得更尖、更拘谨，也会削弱本人真实的亲和感。**

## 7. 动态身份：笑容必须是“整张脸一起笑”，并保留她自己的灵气

连续试画暴露了一个稳定问题：

> **只把嘴角抬起来，会形成很假的笑。**

本人真实笑容不是“嘴在笑，脸没动”，而是：

- 颧骨抬高；
- 苹果肌明显上提；
- 鼻子两侧和眼下的面中体积一起变化；
- 下眼睑被苹果肌轻微顶起；
- 外眼角参与；
- 单眼皮状态下，眼睛会自然弯、自然变窄；
- 眼神仍然有光、有回应；
- 嘴角自然上扬；
- 嘴角向下到下巴附近，会出现非常细、自然的牵拉线 / 表情线；
- 下半脸也会因为笑容出现轻微提拉，不是静止不动。

因此要把笑容理解成：

> **眼睛 + 颧骨 + 苹果肌 + 嘴 + 下半脸一起发生的动作。**

### 笑容禁止项

不要：

- 只拉嘴角；
- 眼睛完全不动；
- 苹果肌不起来；
- 颧骨仍停留在平静位置；
- 眼睛画大来假装“开心”；
- 笑时仍是一张平脸；
- 把嘴角到下巴的自然表情线全部磨掉；
- 做商业证件照式假笑。

验收时先问：

> **不看嘴，只看眼睛和面中，能不能看出她在笑？**

如果不能：

> **这张笑脸就不通过。**

### 7.1 她的笑不是标准甜笑：有一点“努嘴角”的假笑感

用户进一步指出一个非常稳定的动态特征：

> **她笑的时候经常会有一点努着嘴角的感觉，像“假笑”，但这是她本人长期的表情习惯之一。**

这里的“假笑”不是敷衍，也不是不开心。

更像：

- 嘴角有一点主动往外 / 往上撑；
- 有时不是完全对称；
- 嘴唇不是单纯放松微笑，而有一点“抿住 / 努住”的感觉；
- 这会把下半脸横向轻微撑开；
- 脸颊和下颌前段的软组织被牵动；
- 在某些角度下，会让下巴视觉上显得更尖一点；
- 同时会形成她那种有点小机灵、小坏笑、古灵精怪的感觉。

关键区分：

> **她的静态骨相不是尖下巴。**

但：

> **某些笑法 + 轻侧转角度，可以让圆润下巴在照片里暂时显得更尖。**

所以以后必须把这两层分开：

~~~text
静态脸型基线
= 长一点 + 圆润 + 柔和下颌 + 圆下巴 + 少量婴儿肥

动态表情变形
= 努嘴角 / 假笑感
→ 下半脸被撑开
→ 某些角度下下巴视觉上更尖
~~~

禁止把“表情造成的尖”写回默认脸型。

### 7.2 她的表情气质

她的笑长期不是标准甜妹笑，而是：

- 温柔；
- 可爱；
- 有一点狡黠 / 小邪气；
- 古灵精怪；
- 很有主意；
- 像心里一直有自己的想法；
- 亲切，但不呆、不傻甜。

视觉上优先表现：

- 眼神仍然软、松、略朦胧；
- 嘴角带一点本人习惯性的“努”；
- 苹果肌、颧骨、眼睛和下半脸一起参与；
- 不追求对称、标准、广告式微笑。

## 8. 不锁死的外观变量

下面这些不是身份本身：

- 扎发 / 披发；
- 刘海；
- 帽子；
- 眼镜；
- 妆容；
- 穿搭；
- 胖瘦；
- 皮肤状态；
- 精神状态；
- 年龄阶段；
- 当前故事里的职业和生活状态。

其中：

> **眼镜尤其不能作为“认出她”的必要条件。**

后续必须能同时通过：

- 不戴眼镜；
- 戴眼镜；

两种状态认出是同一个人。

## 9. 当前生成禁止项

后续试画优先检查以下错误：

1. 把“长脸”画成“窄脸 + 尖下巴”；
2. 为了婴儿肥把整张脸横向画胖；
3. 头顶画尖、画窄；
4. 额头 / 太阳穴区域过窄；
5. 五官随着长脸一起被上下拉散；
6. 下巴被画尖；
7. 脸被削成明显 V 型；
8. 颧骨被美化掉或画平；
9. 鼻子两侧的苹果肌被磨平；
10. 苹果肌只靠腮红表现，没有真实体积；
11. 颧骨下方的局部婴儿肥被误画成整张胖脸；
12. 不分时期把所有照片都强行统一成单眼皮或双眼皮；
13. 眼皮变化时顺带把眉眼关系、眼睛大小和脸型一起改掉；
14. 眼睛被放大；
15. 把“朦胧感”误画成失焦、困倦、无神或瞳孔模糊；
16. 眼白暴露过多、眼神过锐、过亮、过“盯人”；
17. 嘴画得过小；
18. 笑容只动嘴，不动眼睛、苹果肌和颧骨；
19. 嘴角到下巴的自然细表情线被全部磨掉；
20. 把她的灵动 / 古灵精怪画成标准甜妹笑；
21. 3/4 或侧脸时把颧骨下方软组织和婴儿肥画没；
22. 3/4 或侧脸时把下颌转折画成清晰尖角；
23. 3/4 或侧脸时把下巴拉长、拉尖；
24. 五官被统一成模板美女；
25. 为了“更漂亮”改变本人头脸结构；
26. 不同画风实际偷偷换了不同的脸。

## 10. 下一轮正确的校准方式

当前不再做多画风。

先只做一张：

> **Identity Calibration Board｜身份校准板**

### 参考使用规则

**结构基线只用现在照片。**

板内优先放：

1. 现在正脸 / 接近正脸；
2. 现在自然微笑；
3. 现在轻 3/4；
4. 必要时补一张现在生活照。

年轻照片不进入这张结构校准板的主参考区。

它们只在旁边作为：

> **表情机制补充说明：努嘴角时，下巴会因为表情与角度视觉上变尖，但静态骨相仍然圆润。**

### 只画三张

使用同一种中性、轻半写实、低风格干扰的画法：

- 正脸自然；
- 正脸微笑；
- 轻 3/4。

暂时不画纯侧脸，也不比较六种画风。

### 当前验收

1. 头顶是不是宽而圆？
2. 头脸是不是纵向偏长，但没有变成窄尖脸？
3. 五官是不是相对集中？
4. 颧骨和苹果肌是不是有真实立体感？
5. 下颌是不是柔和连续，没有明显尖角？
6. 静态下巴是不是圆润，而不是尖？
7. 颧骨下方 / 下巴两侧是不是保留少量软组织和婴儿肥？
8. 眼神是不是软、松、有一点雾感，而不是锐利或无神？
9. 微笑时是不是有一点本人习惯性的“努嘴角 / 假笑感”，但没有把动态尖感误当骨相？
10. 不看说明，第一眼像不像本人？

如果这张没有通过：

> **继续只修身份，不进入画风。**
