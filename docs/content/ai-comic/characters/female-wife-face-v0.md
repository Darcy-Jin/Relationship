## 1.1 参考照片怎么使用：结构基线与补充证据分开

2026-09-25 进一步校准：

> **所有照片都属于同一个人，但不同照片承担的用途不同。不能让某一张有明显角度或表情变形的照片，反过来定义她的静态脸型。**

当前正式分成两类参考：

### A. 结构基线：优先使用现在的照片

当前身份校准与后续重画，优先使用现在的：

- 正脸；
- 接近正脸；
- 自然表情；
- 自然微笑；
- 轻微 3/4。

它们主要决定：

- 头脸整体长宽关系；
- 头顶 / 额头宽度与圆润度；
- 颧骨与苹果肌的体积；
- 下颌收束；
- 下巴圆润度；
- 五官在整张脸上的相对位置；
- 现在的眼皮状态与眼神。

### B. 补充证据：年轻照片用于验证长期稳定特征与表情机制

年轻时期照片继续保留，而且非常重要。

但它们主要用于：

1. 验证很多脸部特征从年轻到现在一直稳定存在；
2. 补充现在照片不容易看清的表情变化；
3. 说明某些“变尖 / 变窄”的视觉效果来自角度或表情，而不是骨相本身。

例如：

> **年轻时期某些轻侧转 + 努嘴角的照片，会让下巴视觉上显得更尖。这个尖感是动态与角度造成的，不应该写回静态脸型基线。**

因此后续严格遵守：

> **现在照片定结构；年轻照片补充跨年龄验证与表情机制。**

不是：

> 用年轻侧转照片重新定义一张更尖的脸。

## 1.2 跨年龄稳定的身份特征

年轻照片与现在照片共同证明，以下特征长期稳定：

- 头脸纵向偏长；
- 头顶和额头圆润、有宽度；
- 下颌转折柔和，不形成尖角；
- 静态正面下巴圆润，不是尖下巴；
- 颧骨有存在感；
- 鼻侧 / 眼下苹果肌有体积；
- 颧骨下方到下颌前段有一点自然软组织 / 轻微婴儿肥；
- 五官在较长头脸上显得相对集中；
- 整体亲切、可爱、灵动，而不是美型、冷艳、锐利。

眼皮属于真实时间变化：

- 早期以单眼皮为主；
- 后期做过双眼皮。

这属于同一个人的真实变化，不是身份漂移。

## 3. 第一优先级：头脸整体比例

### 3.1 先分清：头长、脸长，不等于脸宽或下巴尖

2026-09-25 连续试画后，用户进一步明确：

> **她的头脸整体是纵向偏长，但头顶和下巴都很圆润。**

之前两种错误都要避免：

- 为了“长”把下巴拉尖；
- 为了“可爱 / 婴儿肥”把整张脸横向加宽，画胖。

正确方向是：

> **纵向更长 + 横向中等 + 头顶圆润偏宽 + 下巴圆润。**

也就是说：

- 脸不是短圆；
- 也不是窄尖；
- 是较长的鹅蛋型 / 长椭圆，但两端都柔和、圆润；
- 颧骨以下可以慢慢收，但不能快速削成 V。

### 3.2 头顶与额头：比前几版更宽、更圆

当前要明确修正：

- 头顶不能尖、不能像小山峰；
- 头顶部轮廓是比较完整的圆弧；
- 额头和太阳穴区域比前几版要宽一点；
- 额头宽度和颧骨区宽度相对接近，不要上窄下宽；
- 发型可以变化，但不能靠头发把头顶收尖。

一句话：

> **上半个头是圆而有宽度的，不是尖顶。**

### 3.3 脸长与五官“集中感”

用户指出一个很重要的识别感：

> **因为整个头脸偏长，眼、鼻、嘴反而显得更集中在脸中间。**

这不是把五官真的挤成一团，而是保持：

- 头顶 / 额头有足够纵向空间；
- 下巴 / 下半脸也有足够纵向空间；
- 眼、鼻、嘴之间的距离不要被“拉长脸”一起等比例拉开；
- 五官整体在脸中央形成较紧凑的视觉组团。

这会带来本人比较明显的：

> **可爱、亲切、稍带幼态的感觉。**

后续不能只复制单个五官，必须检查：

> **五官在整张长脸上的相对位置。**

### 3.4 原图比例校准（近似参考，不作为生物测量）

以当前最接近正面的无眼镜生活照为主参考，受镜头和表情影响，仅用于生成约束：

- 头顶到下巴的整体纵向长度，约为最大脸宽的 **1.35～1.40 倍**；
- 发际线到下巴的可见脸长，约为最大脸宽的 **1.18～1.25 倍**；
- 额头 / 太阳穴区域不要明显窄于颧骨区；
- 颧骨区是主要横向支撑点；
- 下颌宽度小于颧骨宽度，但差值不能大到形成尖 V；
- 眼睛到嘴巴的主要五官区域，只占整个“头顶到下巴”纵向高度的大约三分之一上下，因此视觉上会觉得五官相对集中。

这些比例的目的不是追求毫米级复刻，而是防止生成模型：

> **把“长脸”误解成“窄脸 + 尖下巴 + 五官拉开”。**

### 3.5 下巴：问题不只是“尖不尖”，而是下巴与两侧软组织的组合

对比当前第 3、4 张生活照后，进一步明确：

> **生成图的问题既有下巴本身过窄 / 过尖，也有下巴两侧、颧骨下方的软组织被画没。**

真实结构更接近：

- 下巴末端是圆钝的小弧面，不是一个点；
- 下巴宽度不能收得太窄；
- 下巴两侧仍然有一点软肉 / 嘟嘟肉，与下颌前段连续；
- 从两侧下颊到下巴，是缓慢连续的 U / 椭圆式收束，不是 V 型两条直线汇到一点；
- 微笑时，面中和脸颊被撑起后，下巴可能相对显得更小，但不能因此真的把下巴画尖。

因此以后不要只问：

> “下巴够不够圆？”

还要同时问：

> **“下巴旁边的肉有没有被保住？”**

正确感觉：

> **脸偏长，但下半脸仍然软、圆、可爱。**

错误方向：

> **窄下巴 + 两侧缺肉 = 美型 / 尖脸。**

### 3.6 3/4 与侧脸：不能把正脸“削尖”以后当成侧脸

当前身份校准板暴露出一个明显问题：

> **正脸已经接近方向，但一转到 3/4 / 侧脸，模型又自动把下颌和下巴画尖，婴儿肥也消失了。**

真实侧面应该继续保留正脸里的“柔软体积”，而不是换成另一种骨相。

#### 侧脸的正确结构

当前“侧脸怪”的问题，**颧骨 / 中脸体积不足确实是重要原因之一**，但不是唯一原因。

侧面必须同时保留：

- 眼下到颧骨前方有一个柔和的前向凸起，不能整块画平；
- 颧骨高点存在，但边缘是软的，不做尖锐骨点；
- 苹果肌从正面转到侧面后仍有体积，不是消失；
- 颧骨下方不能立刻塌进去或形成明显凹面；
- 下颊到下颌前段仍然保留一点软组织 / 婴儿肥；
- 下颌角不是清晰尖角，而是被软组织包住的柔和转折；
- 从耳下 / 后颊到下巴，是缓慢连续的弧线；
- 下巴末端短、宽度适中、圆钝，不向前拉成尖点；
- 3/4 角度时，近镜头侧的脸颊不能被“收掉”。

当前生成侧脸之所以像“另一个人”，通常是：

~~~text
中脸过平
+ 颧骨 / 苹果肌消失
+ 下颊软组织消失
+ 下颌线过干净
+ 下巴过尖
↓
变成标准美型侧脸
~~~

正确目标：

> **有颧骨支撑、有苹果肌、有一点肉、圆下巴的侧脸。**

不做“削骨感”“瓜子脸侧影”“美型漫画侧脸”。

#### 为什么现在会“不像”

当前生成的侧脸主要错在：

~~~text
颧骨以下收得太快
+
下颊软组织消失
+
下颌转折太利
+
下巴拉尖
↓
从“可爱、柔和”滑成“漂亮、美型”
~~~

真正的可爱感来自：

> **长一点的头脸 + 五官集中 + 软眼神 + 有体积的颧骨 / 苹果肌 + 下颊一点婴儿肥 + 圆润下巴。**

这些在正脸、3/4、侧脸都必须同时成立。

## 4. 第一优先级：颧骨 + 苹果肌 + 轻微婴儿肥

这一部分是目前“像不像”和“亲不亲切”的关键。

### 4.1 颧骨

她的颧骨比前几版试画都要更有存在感。

需要保留：

- 颧骨位置比较清楚；
- 中脸有真实的立体支撑；
- 不能把鼻子两侧到眼下这一片画成平面；
- 但颧骨不是尖锐、外扩、凌厉型。

正确感觉：

> **有骨点、有立体感，但仍然柔和。**

### 4.2 苹果肌

苹果肌主要在：

> **鼻子两侧、眼下、颧骨前方的面中区域。**

需要保留：

- 静态就有一点自然饱满；
- 微笑时明显向上、向外鼓起；
- 会顶起下眼睑，让眼睛也参与笑；
- 和颧骨一起形成真实面部起伏；
- 不能只给脸颊涂一点红就算苹果肌。

### 4.3 颧骨下方 / 下巴两侧：局部轻微婴儿肥

用户进一步指出：

> **她在颧骨下方、下巴旁边有一点柔软的婴儿肥感。**

这里要非常精确：

- 是局部软组织，不是把整张脸加宽；
- 位置主要在颧骨下方到下颌前段；
- 会让下半脸更柔软、更可爱；
- 但脸整体仍然偏长；
- 下颌仍然是缓慢收束，不是方脸，也不是胖圆脸。

所以：

> **婴儿肥 = 局部软，不等于脸宽。**

对比当前第 3、4 张生活照可以更清楚地看到：

- 正面 / 轻侧转时，颧骨下方并不是立刻凹进去；
- 下颊前段一直有一点柔软体积；
- 下巴两侧也没有完全收空；
- 因此下半脸虽然比颧骨窄，但轮廓仍然是圆滑连续的；
- 这正是“可爱、亲和”而不是“尖、美型”的关键。

这也是前一版“画胖了”的主要原因：

> 把局部肉感错误地变成了整张脸横向变宽。

## 5. 第一优先级：眼睛

眼睛的**稳定身份特征**和**真实时间变化**要分开。

### 5.1 稳定身份特征

无论单眼皮还是后来做过双眼皮，优先保持：

- 眼型自然偏细长；
- 眼睛大小正常偏克制；
- 眼距和眉眼关系保持本人比例；
- 不做少女漫画式大眼；
- 不用放大眼睛来制造“有神”或“好看”；
- 笑时眼睛会自然弯、自然变窄，并参与整张脸的笑。

### 5.2 真实时间变化：单眼皮 → 双眼皮

用户补充：

> **她原来是单眼皮，后来做过双眼皮。**

因此不能再把“单眼皮”写成永久不变的身份锚点。

正确规则：

- 画年轻 / 早期状态时，可按原始单眼皮参考；
- 画现在 / 后期状态时，可按后期真实双眼皮参考；
- 不管是哪一时期，都不能把眼睛自动放大成模板动漫眼；
- 眼皮变化不能带动整套眉眼、脸型、气质一起被重新设计。

一句话：

> **眼皮可以随真实时间变化，眼睛是谁不能变。**

### 5.3 稳定的“朦胧感”：重点是眼睑张力与对比度，不是“无神”

当前生成仍然把她的眼睛画得太“有神”、太清楚。

对照现在照片后，“朦胧”更准确地拆成：

- 上眼睑放松，眼睛纵向开合不大；
- 虹膜上缘通常被上眼睑自然遮住一点；
- 下方眼白暴露很少；
- 眼尾、下眼睑边缘都偏软，不做锐利刀口；
- 瞳孔 / 虹膜 / 眼白之间的明暗反差不要过强；
- 不使用大而硬的高光点制造“闪亮感”；
- 视线有焦点，但没有强烈“直盯镜头”的压迫感；
- 即使看镜头，也像隔着一层很薄的雾：**清醒，但柔。**

这里最容易犯的错误不是“画成没精神”，而是反过来：

~~~text
眼睛开太大
+ 虹膜太亮
+ 黑白反差太强
+ 高光太清楚
+ 眼线太利
↓
变成标准动漫 / 美女的“有神眼”
~~~

这会非常不像她。

更准确的目标：

> **有焦点，但不锐；有灵气，但不亮闪；柔软、松弛、略朦胧。**

生成时不要用这些替代“朦胧”：

- 失焦；
- 困；
- 无神；
- 眼睛发灰；
- 故意模糊瞳孔。

## 6. 第二优先级：其他五官

当前照片足以说明整体身份，但这一阶段不对不确定的小细节过度下结论。

先遵守：

### 眉毛

- 保持自然；
- 不改成锋利、高挑、精修感很强的眉型；
- 眉毛服务真实眉眼关系，不单独“美化”。

### 鼻子

- 保持真实比例；
- 不主动拔高鼻梁；
- 不改成窄、高、挺的模板鼻；
- 不因为半写实画风增加欧美式立体感。

### 嘴

连续试画后修正：

- 嘴不能画得太小；
- 嘴部横向宽度要保留本人自然比例；
- 唇厚自然，不主动丰唇；
- 不使用精致红唇 / 网红唇形替代本人结构；
- 笑起来时嘴角上扬幅度不能只发生在嘴本身，要带动整张脸。

尤其注意：

> **嘴太小，会让中下脸显得更尖、更拘谨，也会削弱本人真实的亲和感。**

## 7. 动态身份：她不是只有一种“标准笑脸”

前几版把规则写成“只要笑，整张脸都必须明显一起笑”，现在需要修正。

对照现在第 3、4 张照片以及其他生活照，可以看到她至少有两种稳定笑法。

### 7.1 习惯性的“假笑 / 努嘴角”

这是非常有本人识别度的一种表情。

特点：

- 嘴角主要是**向两侧拉开，再轻微往上**，不是大幅上扬；
- 嘴唇会有一点抿住、努住的张力；
- 两侧嘴角不一定完全对称；
- 口周和下半脸会显得稍微紧一点，所以会有一点“僵”；
- 眼睛仍然维持本人那种软、松、略朦胧的状态，不一定同步变成夸张笑眼；
- 苹果肌会有变化，但没有“大笑”那么强烈；
- 嘴角向下到下巴附近可以出现细小牵拉线；
- 这种轻微僵硬和小别扭，反而构成她“古灵精怪、有主意”的一部分。

因此：

> **她的习惯性微笑不能被优化成标准甜美微笑。**

“僵一点”在这里不是生成错误，而是需要保留的本人特征。

### 7.2 真正开心 / 大笑

像当前第 4 张生活照那种更开心的状态：

- 颧骨明显上提；
- 苹果肌饱满；
- 下眼睑和眼尾明显参与；
- 眼睛自然变窄；
- 面中横向体积变大；
- 可以露齿；
- 下半脸也被带动。

这种情况下才是：

> **整张脸明显一起笑。**

### 7.3 “笑时下巴变尖”必须理解成动态视觉效应

她努嘴角或轻侧转时：

- 嘴角横向撑开；
- 下颊软组织被牵拉；
- 角度又会压缩一侧脸宽；

所以照片里下巴**可能显得**比自然正脸尖一点。

但这不是骨相改变。

必须保持：

~~~text
静态结构
= 圆下巴 + 柔和下颌 + 下颊软组织

动态视觉
= 努嘴角 / 轻侧转
→ 看起来稍尖
~~~

## 9. 当前生成禁止项

后续试画优先检查以下错误：

1. 把“长脸”画成“窄脸 + 尖下巴”；
2. 为了婴儿肥把整张脸横向画胖；
3. 头顶画尖、画窄；
4. 额头 / 太阳穴区域过窄；
5. 五官随着长脸一起被上下拉散；
6. 下巴被画尖；
7. 脸被削成明显 V 型；
8. 颧骨被美化掉或画平；
9. 鼻子两侧的苹果肌被磨平；
10. 苹果肌只靠腮红表现，没有真实体积；
11. 颧骨下方的局部婴儿肥被误画成整张胖脸；
12. 不分时期把所有照片都强行统一成单眼皮或双眼皮；
13. 眼皮变化时顺带把眉眼关系、眼睛大小和脸型一起改掉；
14. 眼睛被放大；
15. 把“朦胧感”误画成失焦、困倦、无神或瞳孔模糊；
16. 眼白暴露过多、眼神过锐、过亮、过“盯人”；
17. 嘴画得过小；
18. 笑容只动嘴，不动眼睛、苹果肌和颧骨；
19. 嘴角到下巴的自然细表情线被全部磨掉；
20. 把她的灵动 / 古灵精怪画成标准甜妹笑；
21. 3/4 或侧脸时把颧骨下方软组织和婴儿肥画没；
22. 3/4 或侧脸时把下颌转折画成清晰尖角；
23. 3/4 或侧脸时把下巴拉长、拉尖；
24. 五官被统一成模板美女；
25. 为了“更漂亮”改变本人头脸结构；
26. 不同画风实际偷偷换了不同的脸。

## 10. 下一轮正确的校准方式

当前不再做多画风。

先只做一张：

> **Identity Calibration Board｜身份校准板**

### 参考使用规则

**结构基线只用现在照片。**

板内优先放：

1. 现在正脸 / 接近正脸；
2. 现在自然微笑；
3. 现在轻 3/4；
4. 必要时补一张现在生活照。

年轻照片不进入这张结构校准板的主参考区。

它们只在旁边作为：

> **表情机制补充说明：努嘴角时，下巴会因为表情与角度视觉上变尖，但静态骨相仍然圆润。**

### 只画三张

使用同一种中性、轻半写实、低风格干扰的画法：

- 正脸自然；
- 正脸微笑；
- 轻 3/4。

暂时不画纯侧脸，也不比较六种画风。

### 当前验收

1. 头顶是不是宽而圆？
2. 头脸是不是纵向偏长，但没有变成窄尖脸？
3. 五官是不是相对集中？
4. 颧骨和苹果肌是不是有真实立体感？
5. 下颌是不是柔和连续，没有明显尖角？
6. 静态下巴是不是圆润，而不是尖？
7. 颧骨下方 / 下巴两侧是不是保留少量软组织和婴儿肥？
8. 眼神是不是软、松、有一点雾感，而且没有被画成“亮、锐、闪”的有神眼？
9. 习惯性微笑是不是保留了“嘴角横拉 + 略僵 + 努嘴角”的本人特点，而不是被优化成甜妹笑？
10. 真正开心时，颧骨 / 苹果肌 / 眼睛是否才明显一起参与？
11. 3/4 / 侧面是否保住中脸前向体积、颧骨、苹果肌和下颊软组织？
12. 不看说明，第一眼像不像本人？

如果这张没有通过：

> **继续只修身份，不进入画风。**
