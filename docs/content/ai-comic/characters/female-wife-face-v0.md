## 1.1 参考照片怎么使用：Identity 和 Current State 分开

2026-09-25 进一步纠正：

> **不能简单规定“现在照片定结构、年轻照片只做补充”。**

更准确的关系是：

~~~text
以前照片 + 现在照片
↓
共同寻找跨年龄稳定特征
↓
Identity｜她是谁

现在照片
↓
决定当前年龄、眼皮、软组织、发型、眼镜、皮肤、胖瘦等
↓
Current State｜现在的她是什么状态
~~~

### A. Identity Evidence｜身份证据

以前和现在的照片都属于**同等重要的身份材料**。

它们共同回答：

- 哪些头脸比例长期没变；
- 哪些五官关系长期没变；
- 哪些颧骨 / 苹果肌 / 下颌 / 下巴关系长期没变；
- 哪些眼神、笑法、表情习惯长期稳定；
- 哪些只是某张照片的角度、表情、镜头或年龄造成的变化。

原则：

> **一张照片不能定义她，多张跨时间照片的共同部分才更接近 Identity。**

### B. Identity Master｜长期稳定的“这张脸是谁”

Identity Master 不等于任何一张具体照片。

它应该综合跨年龄照片，锁住：

- 小而紧凑、偏窄长的椭圆头脸包络；
- 五官相对集中；
- 头顶圆润；
- 颧骨与苹果肌体积；
- 柔和下颌；
- 圆润下巴；
- 下颊 / 下巴两侧少量软组织；
- 眼神软、松、略朦胧；
- 有辨识度的努嘴角 / 略僵 / 古灵精怪的笑法。

### C. Current State｜现在的她

当目标是画“现在的她”时，再由现在照片决定：

- 当前年龄感；
- 当前双眼皮状态；
- 当前胖瘦与面部软组织状态；
- 当前皮肤状态；
- 当前发型；
- 是否戴眼镜；
- 当前妆容与精神状态。

因此：

> **Identity 决定“还是不是她”；Current State 决定“今天的她长什么状态”。**

### D. 实际生成时不要把所有历史照片一次性塞进去

生成阶段默认使用：

~~~text
已确认 Identity 文字约束
+
少量当前目标状态照片
↓
生成
~~~

以前照片主要用于：

- 前期建立 Identity；
- 当生成结果漂移时做纠偏；
- 验证某个特征是否跨年龄稳定。

这样既保留跨年龄身份信息，又避免视觉参考过多导致模型串线。

## 1.2 跨年龄稳定的身份特征

年轻照片与现在照片共同证明，以下特征长期稳定：

- 头脸纵向偏长；
- 头顶和额头圆润、有宽度；
- 下颌转折柔和，不形成尖角；
- 静态正面下巴圆润，不是尖下巴；
- 颧骨有存在感；
- 鼻侧 / 眼下苹果肌有体积；
- 颧骨下方到下颌前段有一点自然软组织 / 轻微婴儿肥；
- 五官在较长头脸上显得相对集中；
- 整体亲切、可爱、灵动，而不是美型、冷艳、锐利。

眼皮属于真实时间变化：

- 早期以单眼皮为主；
- 后期做过双眼皮。

这属于同一个人的真实变化，不是身份漂移。

虽然该版本视觉上明显吸收了较早时期照片的状态特征，但这次结果不能简单判为“参考错了”。

更合理的解释是：

> **较早照片里确实包含很多长期稳定的 Identity 特征，所以混入以后反而更像本人。**

因此这版作为**正样本 / Positive Sample**保留其有效结论：

- 小、紧凑、偏窄长的椭圆头脸；
- 五官在脸上相对集中；
- 下半脸不能做成 V；
- 圆下巴与下巴两侧软组织同时存在；
- 整体是可爱、温柔、灵动，而不是尖锐美型。

但它**还不能直接升级为 Identity Master**，因为：

- 当前状态与历史状态仍有混合；
- 眼神、习惯性假笑、侧脸体积仍需继续校准；
- 当前目标还要验证“同一 Identity 在现在状态下是否仍然像”。

所以当前状态定义为：

> **Positive Sample / Near Pass：身份方向已经明显接近，但还需把 Identity 与 Current State 分离干净。**

## 2.1 本轮测量结论：关键可能不是“圆不圆”，而是外轮廓本来就小、窄、长

2026-09-25 用户提出新的直观假设：

> **她本人的头可能就比较小、比较窄，所以五官放在这张较小的椭圆头脸里，会形成与普通模板脸不同的比例；之前反复调不准，可能一直把“窄”误解成“尖”，又把“婴儿肥”误解成“宽”。**

重新对照现在照片，并把一张接近正面的当前照片校正倾斜后做像素级粗测，得到：

- 头顶到下巴的整体高度 / 最大头脸宽度，约 **1.35～1.40**；
- 眼线到嘴线这一组主要五官的纵向区域，只占整个头高约 **30～32%**；
- 头顶 / 额头到眼线之间的空间相对充足，所以眼、鼻、嘴视觉上更像聚在头脸中央；
- 下半脸虽然逐渐收窄，但收得很缓；真正的圆润感来自**圆下巴 + 下巴两侧软组织 + 颧骨下方轻微婴儿肥**，不是把整张脸画宽。

这些数值只用于当前图片生成校准，不是医学或人体测量。自拍镜头、距离、角度都会改变绝对尺寸。

### “头小”目前怎么处理

从多人合照里，确实可以看到她长期没有明显“大头 / 大脸”的视觉感受；有些照片中即使位置更靠前，头脸也仍然显得紧凑。

但没有统一焦距、距离和尺度参照，因此目前**不能从这些照片可靠推出真实头围或绝对物理头径**。

所以正式规则暂时写成：

> **绝对“小头”是工作假设；“头脸外轮廓紧凑、偏窄长的小椭圆感”是当前有多张照片支持的视觉事实。**

### 对生成最重要的含义

以后必须同时满足：

~~~text
外轮廓
= 小 / 紧凑 / 窄长 / 椭圆

里面
= 五官相对集中，不随头脸一起缩小或拉散

下半脸
= 有软组织、有婴儿肥、有圆下巴

绝对不是
= 窄长 → V 脸 → 尖下巴
~~~

这可能正是此前反复失败的核心：

> **模型一听“窄、长”就自动做成美型尖脸；一听“婴儿肥、圆润”又把整张脸横向加宽。**

她真正的组合反而是：

> **小而窄长的椭圆外壳 + 有体积的中脸 + 柔软下颊 + 圆下巴 + 相对集中的五官。**

## 3. 第一优先级：头脸整体比例

### 3.1 先分清：头长、脸长，不等于脸宽或下巴尖

2026-09-25 连续试画后，用户进一步明确：

> **她的头脸整体是纵向偏长，但头顶和下巴都很圆润。**

之前两种错误都要避免：

- 为了“长”把下巴拉尖；
- 为了“可爱 / 婴儿肥”把整张脸横向加宽，画胖。

正确方向是：

> **纵向更长 + 横向中等 + 头顶圆润偏宽 + 下巴圆润。**

也就是说：

- 脸不是短圆；
- 也不是窄尖；
- 是较长的鹅蛋型 / 长椭圆，但两端都柔和、圆润；
- 颧骨以下可以慢慢收，但不能快速削成 V。

### 3.2 头顶与额头：相对下半脸要宽圆，但整个头仍然紧凑、偏窄

此前“头顶 / 额头更宽”容易被误读成把整个头画大。

现在改成：

- 头顶不能尖、不能像小山峰；
- 头顶部轮廓是完整柔和的圆弧；
- 额头 / 太阳穴相对于下颌和下巴不能过窄；
- 但整个头脸的绝对视觉包络仍然是**紧凑、偏小、偏窄长**；
- 额头与颧骨区宽度接近，不要上窄下宽，也不要把上半头横向放大；
- 发型可以变化，但不能靠头发把头顶收尖或撑成大头。

一句话：

> **她不是“大而圆的头”，而是“小而窄长的椭圆头，顶部仍然圆润。**

### 3.3 脸长与五官“集中感”

用户指出一个很重要的识别感：

> **因为整个头脸偏长，眼、鼻、嘴反而显得更集中在脸中间。**

这不是把五官真的挤成一团，而是保持：

- 头顶 / 额头有足够纵向空间；
- 下巴 / 下半脸也有足够纵向空间；
- 眼、鼻、嘴之间的距离不要被“拉长脸”一起等比例拉开；
- 五官整体在脸中央形成较紧凑的视觉组团。

这会带来本人比较明显的：

> **可爱、亲切、稍带幼态的感觉。**

后续不能只复制单个五官，必须检查：

> **五官在整张长脸上的相对位置。**

### 3.4 原图比例校准（近似参考，不作为生物测量）

以当前最接近正面的无眼镜生活照为主参考，受镜头和表情影响，仅用于生成约束：

- 头顶到下巴的整体纵向长度，约为最大脸宽的 **1.35～1.40 倍**；
- 发际线到下巴的可见脸长，约为最大脸宽的 **1.18～1.25 倍**；
- 额头 / 太阳穴区域不要明显窄于颧骨区；
- 颧骨区是主要横向支撑点；
- 下颌宽度小于颧骨宽度，但差值不能大到形成尖 V；
- 眼睛到嘴巴的主要五官区域，只占整个“头顶到下巴”纵向高度的大约三分之一上下，因此视觉上会觉得五官相对集中。

这些比例的目的不是追求毫米级复刻，而是防止生成模型：

> **把“长脸”误解成“窄脸 + 尖下巴 + 五官拉开”。**

### 3.5 下巴：问题不只是“尖不尖”，而是下巴与两侧软组织的组合

对比当前第 3、4 张生活照后，进一步明确：

> **生成图的问题既有下巴本身过窄 / 过尖，也有下巴两侧、颧骨下方的软组织被画没。**

真实结构更接近：

- 下巴末端是圆钝的小弧面，不是一个点；
- 下巴宽度不能收得太窄；
- 下巴两侧仍然有一点软肉 / 嘟嘟肉，与下颌前段连续；
- 从两侧下颊到下巴，是缓慢连续的 U / 椭圆式收束，不是 V 型两条直线汇到一点；
- 微笑时，面中和脸颊被撑起后，下巴可能相对显得更小，但不能因此真的把下巴画尖。

因此以后不要只问：

> “下巴够不够圆？”

还要同时问：

> **“下巴旁边的肉有没有被保住？”**

正确感觉：

> **脸偏长，但下半脸仍然软、圆、可爱。**

错误方向：

> **窄下巴 + 两侧缺肉 = 美型 / 尖脸。**

### 3.6 3/4 与侧脸：不能把正脸“削尖”以后当成侧脸

当前身份校准板暴露出一个明显问题：

> **正脸已经接近方向，但一转到 3/4 / 侧脸，模型又自动把下颌和下巴画尖，婴儿肥也消失了。**

真实侧面应该继续保留正脸里的“柔软体积”，而不是换成另一种骨相。

#### 侧脸的正确结构

当前“侧脸怪”的问题，**颧骨 / 中脸体积不足确实是重要原因之一**，但不是唯一原因。

侧面必须同时保留：

- 眼下到颧骨前方有一个柔和的前向凸起，不能整块画平；
- 颧骨高点存在，但边缘是软的，不做尖锐骨点；
- 苹果肌从正面转到侧面后仍有体积，不是消失；
- 颧骨下方不能立刻塌进去或形成明显凹面；
- 下颊到下颌前段仍然保留一点软组织 / 婴儿肥；
- 下颌角不是清晰尖角，而是被软组织包住的柔和转折；
- 从耳下 / 后颊到下巴，是缓慢连续的弧线；
- 下巴末端短、宽度适中、圆钝，不向前拉成尖点；
- 3/4 角度时，近镜头侧的脸颊不能被“收掉”。

当前生成侧脸之所以像“另一个人”，通常是：

~~~text
中脸过平
+ 颧骨 / 苹果肌消失
+ 下颊软组织消失
+ 下颌线过干净
+ 下巴过尖
↓
变成标准美型侧脸
~~~

正确目标：

> **有颧骨支撑、有苹果肌、有一点肉、圆下巴的侧脸。**

不做“削骨感”“瓜子脸侧影”“美型漫画侧脸”。

#### 为什么现在会“不像”

当前生成的侧脸主要错在：

~~~text
颧骨以下收得太快
+
下颊软组织消失
+
下颌转折太利
+
下巴拉尖
↓
从“可爱、柔和”滑成“漂亮、美型”
~~~

真正的可爱感来自：

> **长一点的头脸 + 五官集中 + 软眼神 + 有体积的颧骨 / 苹果肌 + 下颊一点婴儿肥 + 圆润下巴。**

这些在正脸、3/4、侧脸都必须同时成立。

## 4. 第一优先级：颧骨 + 苹果肌 + 轻微婴儿肥

这一部分是目前“像不像”和“亲不亲切”的关键。

### 4.1 颧骨

她的颧骨比前几版试画都要更有存在感。

需要保留：

- 颧骨位置比较清楚；
- 中脸有真实的立体支撑；
- 不能把鼻子两侧到眼下这一片画成平面；
- 但颧骨不是尖锐、外扩、凌厉型。

正确感觉：

> **有骨点、有立体感，但仍然柔和。**

### 4.2 苹果肌

苹果肌主要在：

> **鼻子两侧、眼下、颧骨前方的面中区域。**

需要保留：

- 静态就有一点自然饱满；
- 微笑时明显向上、向外鼓起；
- 会顶起下眼睑，让眼睛也参与笑；
- 和颧骨一起形成真实面部起伏；
- 不能只给脸颊涂一点红就算苹果肌。

### 4.3 颧骨下方 / 下巴两侧：局部轻微婴儿肥

用户进一步指出：

> **她在颧骨下方、下巴旁边有一点柔软的婴儿肥感。**

这里要非常精确：

- 是局部软组织，不是把整张脸加宽；
- 位置主要在颧骨下方到下颌前段；
- 会让下半脸更柔软、更可爱；
- 但脸整体仍然偏长；
- 下颌仍然是缓慢收束，不是方脸，也不是胖圆脸。

所以：

> **婴儿肥 = 局部软，不等于脸宽。**

对比当前第 3、4 张生活照可以更清楚地看到：

- 正面 / 轻侧转时，颧骨下方并不是立刻凹进去；
- 下颊前段一直有一点柔软体积；
- 下巴两侧也没有完全收空；
- 因此下半脸虽然比颧骨窄，但轮廓仍然是圆滑连续的；
- 这正是“可爱、亲和”而不是“尖、美型”的关键。

这也是前一版“画胖了”的主要原因：

> 把局部肉感错误地变成了整张脸横向变宽。

## 5. 第一优先级：眼睛

眼睛的**稳定身份特征**和**真实时间变化**要分开。

### 5.1 稳定身份特征

无论单眼皮还是后来做过双眼皮，优先保持：

- 眼型自然偏细长；
- 眼睛大小正常偏克制；
- 眼距和眉眼关系保持本人比例；
- 不做少女漫画式大眼；
- 不用放大眼睛来制造“有神”或“好看”；
- 笑时眼睛会自然弯、自然变窄，并参与整张脸的笑。

### 5.2 真实时间变化：单眼皮 → 双眼皮

用户补充：

> **她原来是单眼皮，后来做过双眼皮。**

因此不能再把“单眼皮”写成永久不变的身份锚点。

正确规则：

- 画年轻 / 早期状态时，可按原始单眼皮参考；
- 画现在 / 后期状态时，可按后期真实双眼皮参考；
- 不管是哪一时期，都不能把眼睛自动放大成模板动漫眼；
- 眼皮变化不能带动整套眉眼、脸型、气质一起被重新设计。

一句话：

> **眼皮可以随真实时间变化，眼睛是谁不能变。**

### 5.3 稳定的“朦胧感”：重点是眼睑张力与对比度，不是“无神”

当前生成仍然把她的眼睛画得太“有神”、太清楚。

对照现在照片后，“朦胧”更准确地拆成：

- 上眼睑放松，眼睛纵向开合不大；
- 虹膜上缘通常被上眼睑自然遮住一点；
- 下方眼白暴露很少；
- 眼尾、下眼睑边缘都偏软，不做锐利刀口；
- 瞳孔 / 虹膜 / 眼白之间的明暗反差不要过强；
- 不使用大而硬的高光点制造“闪亮感”；
- 视线有焦点，但没有强烈“直盯镜头”的压迫感；
- 即使看镜头，也像隔着一层很薄的雾：**清醒，但柔。**

这里最容易犯的错误不是“画成没精神”，而是反过来：

~~~text
眼睛开太大
+ 虹膜太亮
+ 黑白反差太强
+ 高光太清楚
+ 眼线太利
↓
变成标准动漫 / 美女的“有神眼”
~~~

这会非常不像她。

更准确的目标：

> **有焦点，但不锐；有灵气，但不亮闪；柔软、松弛、略朦胧。**

生成时不要用这些替代“朦胧”：

- 失焦；
- 困；
- 无神；
- 眼睛发灰；
- 故意模糊瞳孔。

## 7. 动态身份：她不是只有一种“标准笑脸”

前几版把规则写成“只要笑，整张脸都必须明显一起笑”，现在需要修正。

对照现在第 3、4 张照片以及其他生活照，可以看到她至少有两种稳定笑法。

### 7.1 习惯性的“假笑 / 努嘴角”

这是非常有本人识别度的一种表情。

特点：

- 嘴角主要是**向两侧拉开，再轻微往上**，不是大幅上扬；
- 嘴唇会有一点抿住、努住的张力；
- 两侧嘴角不一定完全对称；
- 口周和下半脸会显得稍微紧一点，所以会有一点“僵”；
- 眼睛仍然维持本人那种软、松、略朦胧的状态，不一定同步变成夸张笑眼；
- 苹果肌会有变化，但没有“大笑”那么强烈；
- 嘴角向下到下巴附近可以出现细小牵拉线；
- 这种轻微僵硬和小别扭，反而构成她“古灵精怪、有主意”的一部分。

因此：

> **她的习惯性微笑不能被优化成标准甜美微笑。**

“僵一点”在这里不是生成错误，而是需要保留的本人特征。

### 7.2 真正开心 / 大笑

像当前第 4 张生活照那种更开心的状态：

- 颧骨明显上提；
- 苹果肌饱满；
- 下眼睑和眼尾明显参与；
- 眼睛自然变窄；
- 面中横向体积变大；
- 可以露齿；
- 下半脸也被带动。

这种情况下才是：

> **整张脸明显一起笑。**

### 7.3 “笑时下巴变尖”必须理解成动态视觉效应

她努嘴角或轻侧转时：

- 嘴角横向撑开；
- 下颊软组织被牵拉；
- 角度又会压缩一侧脸宽；

所以照片里下巴**可能显得**比自然正脸尖一点。

但这不是骨相改变。

必须保持：

~~~text
静态结构
= 圆下巴 + 柔和下颌 + 下颊软组织

动态视觉
= 努嘴角 / 轻侧转
→ 看起来稍尖
~~~

生成时最忌讳：

> **拿动态尖感去重新设计一个永久尖下巴。**

### 7.4 她的表情气质

总体不是标准甜妹，而是：

- 温柔；
- 可爱；
- 有一点狡黠 / 小邪气；
- 古灵精怪；
- 很有主意；
- 像心里一直有自己的想法；
- 亲切，但不呆、不傻甜。

## 9. 当前生成禁止项

后续试画优先检查以下错误：

- 把“头脸小 / 窄长”画成“V 脸 + 尖下巴”；
- 为了婴儿肥把整个头脸横向放大、画胖；
- 为了“头顶圆”把整个头画得又大又宽；
- 头顶画成尖顶；
- 额头 / 太阳穴区域过窄；
- 五官随着长脸一起被上下拉散；
- 下巴被画尖；
- 脸被削成明显 V 型；
- 颧骨被美化掉或画平；
- 鼻子两侧的苹果肌被磨平；
- 苹果肌只靠腮红表现，没有真实体积；
- 颧骨下方的局部婴儿肥被误画成整张胖脸；
- 不分时期把所有照片都强行统一成单眼皮或双眼皮；
- 眼皮变化时顺带把眉眼关系、眼睛大小和脸型一起改掉；
- 眼睛被放大；
- 把“朦胧感”误画成失焦、困倦、无神或瞳孔模糊；
- 眼白暴露过多、眼神过锐、过亮、过“盯人”；
- 嘴画得过小；
- 笑容只动嘴，不动眼睛、苹果肌和颧骨；
- 嘴角到下巴的自然细表情线被全部磨掉；
- 把她的灵动 / 古灵精怪画成标准甜妹笑；

- 3/4 或侧脸时把下巴拉长、拉尖；
- 五官被统一成模板美女；
- 为了“更漂亮”改变本人头脸结构；
- 不同画风实际偷偷换了不同的脸。

### 当前验收

6. 静态下巴是不是圆润，而且下巴两侧软组织还在？
7. 颧骨下方 / 下颊有没有一点柔软体积，但没有把整脸画胖？
8. 眼神是不是软、松、有一点雾感，而且没有被画成“亮、锐、闪”的有神眼？
9. 习惯性微笑是不是保留“嘴角横拉 + 略僵 + 努嘴角”的本人特点？
