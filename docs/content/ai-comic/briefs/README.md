## 为什么选这 5 篇

它们不是当前“最热门的 5 篇”。

它们故意跨不同类型：

~~~text
事业资源
家庭边界
财务生活方式
情绪 / 关系过程
日常家务 / Mental Load
~~~

用来验证同一套 Content Model 是否能处理不同问题，而不是只擅长“优点背后的代价”。

## 当前验证点

进入脚本时重点看：

1. Topic 能不能自然拆成 2 页小章节；
2. 每个单元是不是一个具体生活点；
3. Reframe 是真实的不同需要，而不是强行反转；
4. 有没有又从标签直接推行为；
5. 最后一页能不能回到“我想过什么生活”；
6. 一篇需要 2 个还是 3 个小章节更自然。
