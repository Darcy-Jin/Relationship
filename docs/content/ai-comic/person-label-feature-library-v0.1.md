# 人物 / 标签 / 特点库 v0.1

> 状态：Current / Content Planning Asset  
> 作用：保存用户现实中会拿来形容、筛选一个对象的词，并把这些词继续还原成可观察的生活特点。  
> 上游：[人物模型](../../models/person-model.md)  
> 内容组合：[内容地图](content-map-v0.1.md)  
> 单篇生产：[内容模型](content-model.md)

## 1. 这个库不是“人物分类大全”

Relationship 的内容可以从标签进入，但不能停在标签。

正式转换链：

~~~text
用户现实里会说的标签
↓
这个词可能在指什么
↓
需要继续观察什么
↓
放进具体生活场景
↓
出现什么行为
↓
形成什么条件性模式
↓
对不同伴侣意味着什么
~~~

所以本库同时保留两层：

1. **用户语言**：大家真的会说“大厂、老实、顾家、上进、情绪稳定”；
2. **系统展开**：这个词背后到底要继续看什么，不能直接推出什么。

---

# 2. 一个标签条目以后至少要有这些字段

~~~text
Label
= 用户会说的词

Why Attractive / Why Concerning
= 为什么这个词会让人想选 / 担心

Possible Meanings
= 它可能在指哪些不同东西

Do Not Infer
= 不能从这个词直接推出什么

Observable Handles
= 现实里继续观察哪些行为 / 事实

High-value Scenes
= 最适合把它放进哪些生活场景

Likely Reframe
= 换什么需要 / 生活方式后，判断可能改变

Content Status
= Seed / Candidate / Used / Retired
~~~

第一版不要求每个标签全部填满。

先把高价值标签收集起来，再逐个深化。

# 3. 第一层标签地图

当前先按“用户通常从哪里形成第一判断”分成七组。

这只是内容检索 View，不是人格本体分类。

~~~text
A. 现实条件 / 身份
B. 工作 / 事业 / 经济
C. 性格 / 气质 / 第一印象
D. 关系表现 / 相处感受
E. 生活方式 / 习惯
F. 家庭 / 婚育 / 边界
G. 负面警示 / 高冲突标签
~~~

# 4. A｜现实条件 / 身份

这些是相亲、择偶中最容易直接看到和筛选的条件。

## Seed Labels

- 年龄合适；
- 长得好看 / 看着顺眼；
- 高学历；
- 名校；
- 一线城市；
- 本地人；
- 有房；
- 家庭条件好；
- 独生子女；
- 身高高；
- 身材好；
- 不抽烟 / 少喝酒。

### 这组最重要的转换

~~~text
“条件好”
≠
“共同生活一定好”
~~~

内容继续看：

- 这些条件实际改变了什么生活；
- 哪些只是进入候选池的门槛；
- 哪些条件达到“够用”以后边际价值下降；
- 这些条件与关系中的回应、可靠、公平是否有关。

高价值场景：

- 第一次认识 / 相亲；
- 买房与居住；
- 迁移；
- 双方家庭；
- 生孩子后的资源变化。

---

# 5. B｜工作 / 事业 / 经济

这是当前最适合 Relationship 做内容的一组，因为它很容易从“优点”进入“生活方式”。

## Seed Labels

- 大厂；
- 公务员 / 体制内；
- 国企；
- 创业；
- 高收入；
- 工作稳定；
- 会赚钱；
- 事业心强；
- 上进；
- 有野心；
- 工作狂；
- 工作清闲；
- 未来潜力大；
- 当前条件普通但成长快。

### 高价值标签展开

#### 大厂 / 高收入

大家可能喜欢：

- 收入；
- 能力感；
- 平台；
- 生活资源；
- 职业发展。

不能直接推出：

- 一定可靠；
- 一定愿意把钱投入共同生活；
- 一定没时间；
- 一定不顾家。

继续观察：

- 工作时间；
- 工作侵入生活的程度；
- 钱怎样花；
- 关键时刻能否腾出时间；
- 对事业和家庭优先级的真实选择。

高价值场景：

- 恋爱陪伴；
- 同居作息；
- 育儿；
- 父母生病；
- 搬家 / 异地。

#### 事业心强 / 上进

可能在指：

- 有长期目标；
- 愿意投入时间精力；
- 对成长有要求；
- 不满足现状；
- 只是当前阶段特别拼。

不能直接推出：

- 一定高收入；
- 一定没家庭责任；
- 一定成熟；
- 一定以后成功。

继续观察：

- 时间和注意力实际投向；
- 失败时怎么处理；
- 是否允许伴侣也有自己的事业；
- 家庭任务出现时怎样重新分配资源。

#### 工作稳定

可能在指：

- 收入波动小；
- 工作时间可预测；
- 城市稳定；
- 风险偏好低；
- 职业增长慢但可控。

不能直接推出：

- 人一定稳定；
- 关系一定可靠；
- 没有事业心；
- 一定顾家。

# 6. C｜性格 / 气质 / 第一印象

这一组最容易被标签误导，所以必须特别强调“进入场景”。

## Seed Labels

- 老实；
- 温柔；
- 脾气好；
- 情绪稳定；
- 成熟；
- 理性；
- 感性；
- 强势；
- 随和；
- 敏感；
- 内向；
- 外向；
- 幽默；
- 浪漫；
- 有趣；
- 慢热；
- 自信；
- 谨慎；
- 冒险。

### 高价值标签展开

#### 老实

可能在指：

- 不善社交；
- 不会花言巧语；
- 遵守规则；
- 生活简单；
- 冲突少；
- 性经验少；
- 只是给人的第一印象。

不能直接推出：

- 一定忠诚；
- 一定有责任感；
- 一定会尊重伴侣；
- 一定适合结婚。

继续观察：

- 承诺是否执行；
- 有利益冲突时怎么选；
- 如何面对诱惑和边界；
- 不同意时是否真实表达。

#### 脾气好 / 随和

可能在指：

- 情绪反应低；
- 容忍度高；
- 不爱争；
- 习惯迁就；
- 回避冲突；
- 对很多事情真的无所谓。

不能直接推出：

- 一定会沟通；
- 一定不会积怨；
- 一定尊重你的意见。

继续观察：

- 真正不同意时是否表达；
- 同一问题重复出现时怎么处理；
- 是否能提出自己的边界；
- 冲突后能否修复。

#### 情绪稳定 / 理性

可能在指：

- 不容易失控；
- 反应慢；
- 擅长问题解决；
- 情绪表达少；
- 有较强自我调节能力。

不能直接推出：

- 一定会共情；
- 一定不会冷漠；
- 一定适合所有高情绪需求的人。

继续观察：

- 伴侣难受时怎么回应；
- 自己受挫时怎么处理；
- 冲突中是压住情绪还是能真正沟通。

#### 强势

可能在指：

- 决策快；
- 控制感强；
- 责任感强时会接管；
- 对结果要求高；
- 不善让权。

不能直接推出：

- 所有场景都控制；
- 一定大男子主义；
- 一定不讲道理。

继续观察：

- 哪些事情他会抢决定权；
- 低风险场景是否也控制；
- 伴侣意见与自己冲突时怎么处理；
- 能否承认判断错了。

---

# 7. D｜关系表现 / 相处感受

这是用户最容易直接说“适不适合谈恋爱 / 结婚”的一组词。

## Seed Labels

- 顾家；
- 体贴；
- 会照顾人；
- 有责任感；
- 靠谱；
- 专一；
- 会沟通；
- 懂我；
- 尊重人；
- 有边界感；
- 会提供情绪价值；
- 黏人；
- 独立；
- 给空间；
- 有仪式感。

### 高价值标签展开

#### 顾家

可能在指：

- 愿意投入家庭时间；
- 愿意做家务 / 育儿；
- 重视父母；
- 喜欢待在家；
- 希望很多事一起做。

不能直接推出：

- 一定尊重伴侣空间；
- 一定公平分工；
- “家”一定指夫妻小家。

继续观察：

- 时间给谁；
- 钱给谁；
- 家务和照护怎么分；
- 原生家庭和小家的边界。

#### 靠谱 / 有责任感

可能在指：

- 说到做到；
- 计划性强；
- 出问题不逃；
- 关键时刻出现；
- 愿意承担代价。

不能直接推出：

- 平时一定有大量陪伴；
- 一定浪漫；
- 一定会表达情绪。

继续观察：

- 临时变化时会不会主动处理；
- 出错后是否补救；
- 需要牺牲自己利益时是否仍履行承诺。

#### 独立 / 给空间

可能在指：

- 自己能安排生活；
- 不需要高频联系；
- 不控制伴侣；
- 很少求助；
- 不喜欢彼此过度介入。

不能直接推出：

- 一定冷漠；
- 一定边界健康；
- 一定不需要亲密。

继续观察：

- 需要支持时是否愿意求助；
- 伴侣需要帮助时是否介入；
- 个人空间和共同责任发生冲突时怎么处理。

# 8. E｜生活方式 / 习惯

这一组最适合直接画成“每天怎么过”。

## Seed Labels

- 自律；
- 爱健身；
- 爱旅行；
- 爱社交；
- 宅；
- 爱打游戏；
- 节俭；
- 会享受生活；
- 消费高；
- 爱干净；
- 生活规律；
- 夜猫子；
- 爱做饭；
- 喜欢计划；
- 随性；
- 极简；
- 精致。

### 高价值标签展开

#### 自律 / 爱健身

喜欢它的人可能真正喜欢的是：

- 身体状态；
- 精神状态；
- 自我管理；
- 好身材；
- 稳定节奏。

继续展开必须看：

- 每周投入多少时间；
- 饮食和作息限制；
- 能否和伴侣共享；
- 育儿 / 加班后还能否维持。

#### 节俭

可能在指：

- 储蓄率高；
- 不冲动消费；
- 对风险敏感；
- 不重视消费体验；
- 对钱控制感强。

不能直接推出：

- 一定抠门；
- 一定财务健康；
- 一定不愿意为伴侣花钱。

继续观察：

- 必要支出、体验支出、给家人花钱时怎么决定；
- 是否尊重伴侣自己的消费空间；
- 两人财务目标是否一致。

#### 爱社交

可能在指：

- 外向；
- 朋友多；
- 活动多；
- 人脉广；
- 不喜欢独处；
- 工作需要大量社交。

继续观察：

- 周末怎样安排；
- 伴侣是否需要参与；
- 是否提前计划；
- 朋友与伴侣冲突时怎么处理。

# 9. F｜家庭 / 婚育 / 边界

这些词很容易在结婚以后从“观念”变成真实任务。

## Seed Labels

- 孝顺；
- 家庭观念强；
- 想要孩子；
- 不想要孩子；
- 喜欢孩子；
- 愿意带娃；
- 愿意做家务；
- 跟父母关系好；
- 父母开明；
- 家庭关系简单；
- 重视小家庭；
- 边界清楚；
- 传统；
- 男女平等。

### 高价值标签展开

#### 孝顺

可能在指：

- 情感上亲近父母；
- 给父母钱；
- 经常陪伴；
- 重大决定会考虑父母；
- 父母需要时承担照护。

不能直接推出：

- 一定妈宝；
- 一定没有夫妻边界；
- 一定是优点。

真正要看：

- 父母与伴侣意见冲突时怎么处理；
- 时间 / 钱 / 决策怎样分；
- 小家庭边界在哪里。

#### 家庭观念强

可能在指：

- 希望结婚生子；
- 愿意投入家庭；
- 喜欢高共同时间；
- 重视亲属关系；
- 接受传统角色分工。

所以这个标签必须继续问：

> **他想要的是哪一种家庭？**

# 10. G｜负面警示 / 高冲突标签

这组是用户现实里会说，但最容易偷换概念的一组。

## Seed Labels

- 妈宝；
- 大男子主义；
- 控制欲强；
- 情绪化；
- 冷暴力；
- 回避型；
- 讨好型；
- 自私；
- 不成熟；
- 没责任心；
- 花心；
- 恋爱脑；
- 工作狂；
- 过度依赖。

### 使用规则

这组词不能直接作为系统事实。

必须先翻译成：

~~~text
具体发生了什么
↓
在什么场景反复发生
↓
对方真正做了什么
↓
造成了什么影响
↓
有没有回应 / 调整 / 修复
~~~

例如：

> “妈宝”

不能直接作为人物属性。

需要继续拆：

- 多大事情会征求父母意见；
- 父母和伴侣冲突时站哪边；
- 父母是否介入钱、房、孩子；
- 是否能建立小家庭自己的决定边界。

同样：

> “冷暴力”

要继续看：

- 是冲突时短暂需要冷静；
- 还是长期拒绝沟通、惩罚性失联；
- 持续多久；
- 是否明确告知；
- 是否回来修复。

# 11. 第一批优先深化标签

不是所有 Seed 都马上详细建模。

当前优先选择那些：

- 用户非常常用；
- 第一眼看起来像明显优点 / 缺点；
- 一进入共同生活意义就会变化；
- 很容易做成具体场景；
- 能帮助用户反过来认识自己的需要。

第一批建议：

1. 大厂 / 高收入；
2. 事业心强 / 上进；
3. 工作稳定；
4. 老实；
5. 脾气好 / 随和；
6. 情绪稳定 / 理性；
7. 强势；
8. 顾家；
9. 靠谱 / 有责任感；
10. 独立 / 给空间；
11. 自律 / 爱健身；
12. 节俭；
13. 爱社交；
14. 孝顺；
15. 家庭观念强。

这 15 个标签已经覆盖：

- 条件；
- 事业；
- 性格；
- 关系；
- 生活方式；
- 家庭。

足够作为第一轮 Topic 生产底座。

# 12. 标签不是 Topic

正式关系：

~~~text
Label
↓
展开成可观察特点
↓
进入 Content Map
↓
人物 / 特点
×
生活场景
×
伴侣需要
↓
Topic Candidate
~~~

例如：

~~~text
Label
→ 顾家

展开
→ 家庭时间投入高 / 父母联系密 / 喜欢共同做决定

场景
→ 婚后父母频繁参与

伴侣需要
→ 希望小家庭边界清晰

Topic
→ 很顾家的男人：他顾的是你们的小家，还是整个大家庭？
~~~

所以以后不要直接拿标签批量生成标题。

# 13. 当前边界

当前不：

- 建立全人类完整人格 taxonomy；
- 把星座、地域、MBTI 等直接当行为因果；
- 给标签打统一好坏分；
- 把设计标签 `高事业_低陪伴` 等直接暴露给内容用户；
- 把 Seed Label 自动当成正式人物事实。

当前要做的是：

> **保留用户熟悉的语言，但让每个标签都能继续走向具体的人和具体生活。**
