# Content｜Relationship 的内容出口

Relationship 不只有游戏。

内容也是它理解人、关系和选择的一种使用方式。

但要分清：

> **底层知识只有一份，内容只是表达方式。**

当前结构：

~~~text
共享底座
├─ 人物模型
├─ 关系与共同生活模型
└─ 选择 / 取舍 / 时间变化
        ↓
   不同使用方式
   ├─ 游戏：让用户进去体验
   └─ 内容：让用户快速看见一个问题
~~~

## 当前内容方向

- [AI Comic](ai-comic/README.md)

以后如果增加公众号、小红书、视频、文章，默认仍然放在 Content 这一层。

除非它已经拥有独立的现实对象、权限、团队、部署或生命周期，否则不要因为换了一个内容形式就再拆一个平级知识仓库。

## 内容能反过来给底座什么

内容发布以后可以产生：

- 哪些问题最容易被误判；
- 哪些场景最有共鸣；
- 哪些反例能挑战当前模型；
- 哪些真实案例值得继续研究。

但：

> **评论、热度和单个案例只是 Evidence / Signal，不会自动变成正式人物或关系规则。**

需要进入底层时，仍然走 Research → System Impact → Promotion。
