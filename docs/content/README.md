# Content 目录｜当前用于存放 AI 漫画资产

这个目录是**文件组织方式**，不是 Relationship 的正式架构层。

当前正式认知只有三层：

~~~text
Relationship
├─ 底层
├─ 游戏层
└─ AI 漫画层
~~~

其中：

- 底层维护人、关系、共同生活、选择等共享认识；
- 游戏层把底层理解变成可以亲自体验的可能人生；
- AI 漫画层把底层理解变成可以快速看懂的具体故事和漫画。

当前这个目录主要承载：

- [AI Comic](ai-comic/README.md)

以后出现公众号、小红书、视频、文章等形式时，再根据真实关系决定是 AI 漫画层的一种输出、独立应用层，还是其他结构；现在不提前定义一个额外的 Content 层。

## 内容能反过来给底座什么

内容发布以后可以产生：

- 哪些问题最容易被误判；
- 哪些场景最有共鸣；
- 哪些反例能挑战当前模型；
- 哪些真实案例值得继续研究。

但：

> **评论、热度和单个案例只是 Evidence / Signal，不会自动变成正式人物或关系规则。**

需要进入底层时，仍然走 Research → System Impact → Promotion。
