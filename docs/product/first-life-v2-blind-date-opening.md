# First Life v2｜相亲开场正式设计

> 状态：**已正式晋升、待持续试玩验证**  
> 日期：2026-09-24  
> Research 依据：[10｜相亲信息、择偶判断与交互设计研究](../research/10-mate-selection-decision-factor-and-interaction-design.md)  
> 正式信息模型：`spec/v0/information-model.json`  
> 正式交互 Contract：`spec/v0/interaction-contracts.json`

## 当前范围

```text
朋友介绍几个人
↓
一眼看全现实资料
↓
选一个想见的人
↓
完成一次第一次相亲
↓
决定还要不要见
```

暂时不直接跳三个月后。先把“高效认识一个具体的人”做对。

## 1. 产品定位

Relationship 是工具，游戏形式服务于工具效果。

```text
功能有效
↓
交互效率
↓
体验质量
```

体验仍然重要，因为我们依赖玩家进入具体情境以后产生真实反应。

所以：

> **不做无用互动，也不退回纯属性问卷。**

## 2. 相亲阶段只做三件事

1. 给玩家现实中本来就能知道的信息；
2. 用少量高区分度互动，让人物的生活方式和关系方式开始显现；
3. 记录玩家真实选择，为后续 Life Run 提供 Evidence。

## 3. 候选人总览：现实事实直接给

桌面端：4 人优先一屏并排。  
手机端：2×2 紧凑人物墙。

人物卡 / 详情优先展示：

- 照片 / 形象；
- 名字、年龄；
- 当前城市；
- 学历；
- 工作；
- 收入区间 / 稳定性；
- 住房；
- 家庭基本情况；
- 婚恋意图；
- 孩子态度；
- 吸烟饮酒；
- 迁移可能性。

这些信息不做成 Scene 让玩家猜。

## 4. 第一次相亲不使用通用聊天模板

每个人只展开最能区分自己的 2～4 个点。

- 林序：事业投入 / 时间 / 工作侵入 / 回应；
- 周宁：共同生活 / 家庭投入 / 住房现实；
- 许澈：计划性 / 体验消费 / 社交密度 / 边界；
- 沈知：当前条件 / 未来成长 / 独立空间 / 住房时间。

不是每个人都机械聊：

> 旅行 → 周末 → 做饭 → 工作。

话题只在它真的暴露人物差异时出现。

## 5. 每次需要玩家操作，都必须有作用

自然过渡可以自动发生，不要求玩家点击。

只要要求玩家选择，就至少完成一项：

- 得到新信息；
- 暴露人物差异；
- 暴露玩家偏好；
- 形成 trade-off；
- 观察人物回应；
- 改变关系状态；
- 澄清当前 Evidence。

否则删除这个操作。

## 6. 对话必须真的一来一回

例如许澈：

> “我旅行基本不做详细攻略。你呢？”

玩家：

> “我一般会把酒店和路线先定好。”

许澈：

> “那我们这点不太一样。我临时改计划挺多的。”

这里完成：

```text
暴露他
+
暴露玩家
+
明确差异
```

“相同 / 不同”只描述事实，不自动加匹配分。

## 7. Scene 是有目的的 Probe

正式采用“不是意外的意外”。

事业投入高的人，可以出现：

> 刚开完会 / 临时加班 / 工作电话。

消费高的人，可以出现：

> 高价餐厅 / 高消费选择。

社交高的人，可以出现：

> 朋友临时加入 / 周末排满。

家庭投入高的人，可以出现：

> 周末回父母家 / 家庭责任安排。

场景存在的理由是：

> **让玩家看到抽象特点进入现实以后是什么样。**

## 8. 第一次相亲节奏

```text
现实资料
↓
决定见面
↓
直接进入第一个有区分度的话题 / 场景
↓
人物根据玩家回答真实回应
↓
第二个高区分度 Probe
↓
必要时第三个 Probe
↓
还想不想再见
```

删除：

- “坐下聊聊”这种纯推进按钮；
- 大段旁白替人物解释；
- 所有人共用的空对话；
- 已经知道的信息重复询问；
- 每个 Scene 后机械追问“为什么”。

## 9. 与后台的关系

```text
Candidate Facts
→ Show

Resource Allocation
→ Conversation / Compare / Scene

Relationship Process
→ Scene / 后续 Life Run

Event Domains
→ 后续共同生活
```

具体定义见：`spec/v0/information-model.json`。

玩家操作 Contract 见：`spec/v0/interaction-contracts.json`。

## 10. 当前验证标准

第一场相亲先看：

1. 玩家能不能很快看懂这几个人现实上哪里不同；
2. 每次点击是否都能解释“为什么值得点”；
3. 不同人物是不是明显在聊不同的东西；
4. 对方有没有真的接玩家的话；
5. 玩家是不是开始出现真实 trade-off，而不是寻找正确答案；
6. 最后“还见不见”是不是已经有足够信息支撑。

通过以后，再继续往恋爱和共同生活走。
