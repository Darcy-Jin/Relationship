## 用户自己试玩时只看

1. 四个人的现实条件是否一眼看懂；
2. 钱、房、学历等是不是够用，但没有把人物变成简历；
3. 每一次点击是不是都有明确作用；
4. 不同人物是不是明显在聊不同的事情；
5. 人物有没有真的接住玩家的回答；
6. 是否开始出现取舍，而不是寻找标准答案；
7. 最后“还想不想见”是不是已经有依据。
