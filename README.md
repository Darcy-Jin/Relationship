# Relationship

一个关于亲密关系选择的模拟游戏 / 研究项目。

当前还不是开发阶段，正在做的是：

> **先尽可能完整地理解“人是怎么选择伴侣、怎么一起生活、为什么幸福或痛苦、为什么留下或离开”，再从完整模型里裁出一个足够简单、但不失真的游戏模型。**

## 核心问题

这个项目不是帮人寻找“完美对象”。

它真正想帮助玩家回答三个问题：

1. **我真正需要什么？**
2. **我最不能承受什么？**
3. **为了得到我真正需要的东西，我愿意接受哪些不完美？**

最终想让玩家逐渐看清：

> **什么样的不完美的人，和什么样的不完美生活，对我来说仍然值得选择？**

## 当前最重要的认识

我们最后选择的其实不只是“一个人”。

我们是在选择：

> **和这个人在一起以后，我会过什么样的人生。**

因此不能只把人物做成一排静态分数。

需要继续理解：

```text
这个人是什么样
↓
他把时间 / 精力 / 钱 / 注意力花在哪里
↓
形成什么生活方式
↓
两个人放在一起以后怎样互动
↓
在时间、压力和重大事件下会发生什么
↓
玩家真实感受到什么
```

同一个特点，对不同玩家也可能完全不同。

例如“喜欢健身”：

- 两个人都喜欢 → 共同生活；
- 一个人喜欢、另一个喜欢独处 → 各过各的也很好；
- 一个人喜欢、另一个高度需要陪伴 → 可能持续冲突。

所以不能只问：

> “这个特点是优点还是缺点？”

更应该问：

> **“这个特点进入我们的共同生活以后，会变成什么？”**

## 不是把玩家带向“中等”

游戏的目标不是让玩家最后什么都选 5 分。

真正的校准应该让玩家越来越有棱角：

- 哪些东西必须很高；
- 哪些普通就够；
- 哪些低一点完全没关系；
- 哪些别人能忍，我不能；
- 哪些别人很在乎，我根本不在乎；
- 我愿意为了什么，承担什么代价。

> **可以很挑，但要知道自己到底在挑什么。**

## 游戏的核心循环（当前假设）

```text
选择一个人
↓
和他 / 她过一段生活
↓
体验舒服、满足、失望和痛苦
↓
形成新的判断
↓
重新选择
↓
系统提供对照、反例和不同人生
↓
继续校准
```

第一次选错以后，下一次也可能矫枉过正。

所以游戏不是：

> 选错 → 系统告诉你正确答案。

而是：

> **允许玩家反复试不同的人生，逐渐找到自己的边界。**

## 当前阶段

**探索 / 研究 / 建模。**

现在的方向是：

1. 建立尽量完整的“亲密关系与共同生活模型”；
2. 调研相关学术、理论、产品和游戏；
3. 主动寻找反例，修正我们现在的直觉；
4. 从完整模型中挑出真正影响体验和决策的变量；
5. 形成简化游戏模型；
6. 再做最小试玩局验证。

目前**不急着开发，不急着大量写剧情。**
